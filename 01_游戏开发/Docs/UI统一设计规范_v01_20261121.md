## 1. 全页视觉语言

采用国风手绘墨线、平涂大色块和轻薄纸艺层次。整体干净、平滑、统一，先读轮廓与主次，再读必要细节。边缘清楚利落，文字、角色、关卡之间留有空白；不能以装饰填满剩余空间。

保留暖色与角色原有鲜明衣色，避免全局灰淡、过黄或泥褐滤镜。纸面与木桌形成清楚明暗分区：选角以纸面为主，选关和结算露出木桌，但同一种纸、墨和朱印不得随页面更换色相。背景山水用少量连续色块，不密铺山纹、树叶、屋瓦和街坊。

纸感由轮廓、轻微折面、有限的叠纸与印色体现，不靠全页噪点。只在大纸边、装订处和必要折痕留克制的不规则；大面积纸面与衣服保持平整。禁用高频纹理、脏污颗粒、密集小装饰、厚金浮雕、塑料高光和持续发光描边。

角色保持近二维手绘；轮廓可带轻薄米白切边，不做厚重立体贴纸。只有桌面小景、纸页折边和实际接触面使用必要投影；投影方向与光源一致，不给印在纸上的河流、道路、山水加实体高度。

## 2. 色彩、字形与画布

以下色值与尺寸是**统一制作建议**，不是用户已逐个确认的精确取色，也不宣称已从所有原图测得。生成和后续组件应以同一组数值与参考图校准，不自行漂移。

| 用途 | 建议色值 | 使用规则 |
| --- | --- | --- |
| 米白纸面 | #F4E6C8 | 主要内容底，保持大片清洁留白 |
| 墨褐 | #34251D | 文字、主轮廓、未选剪影；不用纯黑厚边包围所有元素 |
| 木褐 | #4F3021 | 外围桌面与少量支撑结构，不压暗正文区域 |
| 朱红 | #B5452C | 主按钮、印章、P2标识；同一页不多处争抢主视觉 |
| 青绿 | #2D7770 | P1标识、少量地图与辅助状态 |
| 金色 | #D6A545 | 已获星级和少量主题强调，使用平涂而非金属浮雕 |

统一以 1920×1080、16:9 设计，四周安全边距建议 64 px；字号、描边和间距按比例缩放。现有1672×941图片及结算v02的1671×941图片为近似16:9评审稿，不能标作已完成1920×1080高清组件。缩到1280×720检查时，角色归属、主操作、星级和主要数值仍须清楚。

页面标题用同一套简练中文书法风格，常规信息用清楚的中文正文字形，数字统一字形与粗细。大名、标题与主成绩形成有限层级；不把所有说明写成书法，不添加诗文、伪汉字和无意义小字来填白。相同功能文案跨页一致。正式实现中动态文字与数值单独排版，不烘焙进背景。

## 3. 共用组件与双人状态

| 组件 | 统一做法 |
| --- | --- |
| 主操作 | 每页只有一个主要强调按钮；朱红平涂纸签、米白字，轻纸边。选关“选择搭档”、选角“入坊”、结算“再来一局”保持同一形制 |
| 次操作 | 米白纸签配墨褐字，视觉弱于主操作；例如“返回选关”。返回箭头使用同一笔形与位置逻辑 |
| 焦点／按下／不可用 | 在共用轮廓内改变描边、印色或轻微压下反馈，不临时换成现代胶囊、霓虹或厚金框。不可用降低强调并给明确状态，不仅依赖颜色 |
| 玩家标识 | P1固定青绿圆标，P2固定朱红菱标，始终带P1/P2编号；全页共享同一尺寸比例、描边和印章处理 |
| 角色头章 | 只保留头部轮廓和少量物种识别负形，单色印章。四动物各一枚，可统一着色；不使用精细肖像、半身照或三维头像 |
| 准备标记 | 玩家归属、角色已选和准备三者分别表达。勾号表示准备；取消准备不把已选角色重新画成剪影 |
| 星级 | 固定三枚同形五角星，等距同大小；获得为金色实心，未获为清楚空心。不能用币纹、奖励章或装饰星代替 |

四头像的物种差异遵循设定图：泡泡圆小耳与低宽口鼻，递蕉头顶毛束与猴脸外轮廓，墨墩圆耳与熊猫负形，烘栗尖耳与两颊外轮廓。减细节后仍须能辨认，不另造角色特征。

已选／未选以角色彩色／剪影表达，按实际 selectedId 更新；焦点不等于选中。两人不能选择同一角色。入坊只有双方选择不同且准备完成时可用，拒绝或冲突不擅改另一位玩家的选择。沿用[双人状态合同](../Art/四动物双人选角UI_v01_20261120/双人选角状态合同_v01_20261120.json)，本规范只统一视觉表达，不增改键位或规则。

## 4. 三页构图与素材边界

**选角：连续长卷。** 泡泡、递蕉、墨墩、烘栗四位动物并排落在同一完整纸卷上，保留角色体形与尾巴差异。未选显示完整可辨剪影，已选显现平涂色彩；名称、P1/P2和准备状态简洁可读。不回到分栏屏风，不加每栏“选择”按钮，不引入人类。选角详情日后沿用同套纸签、头章、字形和颜色，旧详情不直接算已统一。

**选关：印刷台上的册页。** 深暖木桌、明亮纸面、外围少量工具组成稳定环境。底层山水、道路与河流是平面印刷，节点是有折边、支撑和投影的纸小景。视觉顺序改为“铜钱 → 纸张 → 交子”；保留建筑节点时接在交子后方，不能破坏阅读顺序。节点有大小和高低变化，清除底图碎纹与无关装饰。建筑共用同一俯视视角、竖直方向和投影逻辑；屋顶、墙面、底座的平行边与消失方向一致，不能各画各的透视。此顺序是视觉组织要求，不把图示节点自动写为已确认或已实装关卡。

**结算：双页账册。** 保留原参考的左右页主次，左侧展示用户指定的原版竖式交子，加入实际所选两动物头章；右侧显示本局星级、得分与简短完成数据。删除合影与另画横式票。保持原票的币纹、正文、纸坊线描和朱印关系，头章使用留白，不盖住关键文字和边框。底票来自[用户原资源副本](../Art/选角与多关卡UI_参考重构_v05_20261121/参考/用户原资源_交子底票.png)，原档不覆盖。两个头章按实际pair绑定，不能固定为样例角色；这张概念图不代表六组合正式资源全部完成。

地图显示历史最高星级，结算显示本局星级，两者读不同数据。沿用首关2／4／6单对应1／2／3星的联调初值。示例70分＝4张×10＋3单×10，对应1星，仅用于图稿核对，不写存档、不伪造“新纪录”。正式收藏按既有结算条件处理；展示头章不自动解锁收藏。
