# 《交子赶工记》游戏开发交接

2026 年 11 月 9 日 · 供两位开发者同步设计与制作进度

## 一局游戏怎样玩

《交子赶工记》是一款双人合作的工坊游戏。故事发生在以宋代成都为灵感的架空纸艺世界。两名玩家经营同一座交子作坊，从院中抄出一张纸，到屋内印成交子、盖印交付。玩家在开局选用的两位工匠，也会出现在最后印出的票面上。

参考《胡闹厨房》的是固定高位斜俯视镜头、同时操作和工位间交接。合作的乐趣来自两个人手上的活可以错开。例如第一张纸送进印坊后，一人开始印刷，另一人回到浆槽准备第二张。能看清搭档正在做什么、哪一站缺纸，比堆叠更多工位更重要。

| 阶段 | 玩家做什么 | 场景设计要解决的问题 |
| --- | --- | --- |
| 室外造纸 | 处理纸浆、抄起湿纸、干燥，取得可印的纸 | 浆槽和干燥位之间留出搬运空间，湿纸和干纸在俯视镜头下也容易区分 |
| 室内印刷 | 接收干纸，在印台上印出票面，再移到盖印位 | 门开在真实墙体或木构上，室内贯通，入口、印台和盖印位都能走到 |
| 盖印交付 | 完成印记，把交子送到交付位 | 玩家能从画面判断一张票是否已经印好、盖好；交付时能看清本局角色组合 |

## 可选工匠与 Boss

六名工匠都直立，身高、胖瘦和头身比接近。靠耳朵、帽子、尾巴、工具和动作辨认角色。下表的工种用于理解美术和合作分工，具体技能效果、触发条件和数值仍由原型确定。

| 正式名 | 旧素材名 | 形象与工种方向 |
| --- | --- | --- |
| 纸团 | 阿楮 | 戴纸帽的男孩；取纸、运纸 |
| 印桃 | 朱小印 | 女印工；盖印 |
| 泡泡 | 獭团 | 水獭；纸浆、水槽作业 |
| 递蕉 | 折折 | 金丝猴；工位间传递 |
| 墨墩 | 砚砚 | 大熊猫；压印 |
| 烘栗 | 焙焙 | 小熊猫；干燥纸张 |

**墨大嘴**是四足纸兽 Boss，旧图可能标作“墨饕”或“吞票兽”。它与票据、吞票有关。首轮开发可以先打通普通订单，再设计它如何干扰交付以及两人怎样补救。

## 选角怎样影响出票

六选二，双人角色各异，组合不计左右顺序，共 **15 款组合交子**。例如“印桃＋墨墩”和“墨墩＋印桃”共用同一张票面。程序可用两个稳定角色 ID 排序后组成收藏键，避免重复解锁。

票面采用竖幅。上段排钱纹或角色纹章，中段放竖排票文、字号与朱印，下段以木刻感的画面表现本局两位工匠。这样同一款设计可以承担印台上的成品、结算特写和收藏图鉴三个用途。实物交子与角色小卡可沿用这套画面。

## 美术与镜头

- **纸艺世界。** 人物、建筑、工位和道具共用折面、叠纸边缘和有轻重变化的手绘线。用大片平涂色组织画面，让纤维纹理主要出现在宽阔纸面和断边。票面的黑墨与朱印要一眼可辨。
- **角色比例。** 宽方大头、短身体、短四肢，眼睛略大。古装袖口和衣摆保留折纸棱角，头饰避开方块。每个人的轮廓在缩小游戏画面后仍应容易辨认。
- **游玩视角。** 固定高位斜俯视，能同时看到工位台面、角色面部与搬运路线。室外院子与室内印坊共用相机朝向、道具比例和地面尺度。室内可用敞口或切墙表现，门扇要有依附、开启空间和实际通路。
- **表现与实现。** 已探索平面绘本贴纸和立体纸模两种表现。当前考虑手绘定稿、AI 辅助，用 Tripo3D 制作角色／道具／场景模型，再导入 Unity，以固定镜头保留贴纸感。第一批模型应先拿一个角色和一个工位在同一机位试摆，再决定批量制作规格。

## 建议两人先完成的可玩版本

原计划制作周期约一个半月。建议首版范围定为 **一座作坊、两名可选工匠、一种订单、一款组合交子**。先体验两人亲手交接的完整一单，再扩充角色、票面与 Boss。

1. **先搭灰盒。** 用方块标出浆槽、干燥位、印台、印章台、交付位和门洞。接入同机双人移动、取放和操作。在主镜头下测试两人端着纸在门口交会。
2. **跑通一张票。** 先实现“湿纸 → 干纸 → 已印交子 → 已盖印交子 → 交付”。同一个物件在交接时只能有一位持有者，工位只接收相应状态的物料。
3. **替换一组正式美术。** 一人负责角色、工位、票面与反馈，另一人负责 Unity 场景、输入和工位逻辑；两人共同试手感。先对齐比例、角色脚底位置、手持点与工位交互距离。
4. **验收一次双人试玩。** 两人能从选角走到交付，在没有口头讲解时看懂下一步，并在结算图上认出自己选的工匠。通过后再补其余组合和图鉴。

开工时优先共同确定三件事：双人输入设备与键位、第一对试玩工匠、湿纸交给搭档时采用直接递交还是放到交接台。这三项会直接影响工位间距、动作需求和首轮测试。
