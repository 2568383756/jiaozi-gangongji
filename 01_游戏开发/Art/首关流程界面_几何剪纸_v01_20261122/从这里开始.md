# 首关流程界面 · 几何剪纸

2026-11-22 静态美术评审。六张 v02 整页覆盖开张教学、双人局内提示、暂停、图鉴与操作说明。另附两个暂停确认画面、五张可按工序切换的透明提示条和一张共用场景底图。Unity 接入及目标分辨率下的交互验收待程序方完成。

## 六张整页

| 页面 | 打开后重点看什么 |
| --- | --- |
| [01　开张教学](01_开张教学_v02.png) | 示例停在第二步「晾干」。上方显示五步顺序，场内标出空槽，下方对应当前操作。右上角 Enter 可跳过教学。 |
| [02　局内合作 HUD](02_局内合作HUD_v02.png) | 订单、剩余时间和暂停位于上边缘，两位玩家的持物分列下角。示例为朱印交子 0/1、02:16、0 分，泡泡持湿纸、墨墩空手，晾架 A、B 槽分别显示状态。 |
| [03　暂停菜单](03_暂停菜单_v02.png) | 朱赭纸页叠在冻结的场景上。「继续开工」为当前焦点，另有设置、重新开局、返回选关。 |
| [04　组合交子图鉴](04_组合交子图鉴_v02.png) | 左侧大幅竖票，右侧六种双人组合。本例只收录泡泡 × 墨墩，显示 1/6。已收录票用彩色双印与勾签，其余五格为浅色锁票。 |
| [05　组合交子详情](05_组合交子详情_v02.png) | 放大同一张竖式交子，右侧单独展示泡泡（水獭）、墨墩（大熊猫）的头章，可返回图鉴。 |

01—05 均为 1920×1080，06 为 1672×941。页上时间、订单、持物、焦点与收藏进度用于示范界面状态。

## 状态稿与场景底图

- **暂停确认。** 重新开局或离开作坊前先显示原因及后果，默认焦点落在「留在作坊」。两张均为 1920×1080。[重新开局确认](状态/暂停_重新开局确认_v02.png) · [离开作坊、返回选关确认](状态/暂停_离开作坊确认_v02.png)
- **五步教学。** 每步对应一张 1520×200 的 RGBA 提示条，可独立叠加在场景下方。整页预览使用第二步。[抄纸](状态/教学提示/01_抄纸_v02.png) → [晾干](状态/教学提示/02_晾干_v02.png) → [印刷](状态/教学提示/03_印刷_v02.png) → [盖印](状态/教学提示/04_盖印_v02.png) → [交付](状态/教学提示/05_交付_v02.png)
- **共用场景。** 1672×941 的俯视纸坊保留双槽晾架、纸槽、匀墨印刷台、盖印台、交付口与共享台。教学、正式回合和暂停画面使用同一组位置关系。[首关场景底图 v01](分层/首关场景底图_v01.png)

## 玩法与程序交接

| 编号 | 玩家行为 | 程序接入目标与接口 | 对应资产和版本 | 验收情景 |
| --- | --- | --- | --- | --- |
| F10 | 跟随五步教学或按 Enter 跳过 | 按工序、当前槽位与玩家键位切换提示；教学期间停表、不计分 | 01 v02 一张，五步提示 v02 各一张 | 从第二步跳过或完成第五步后进入正式 180 秒回合。清空教学物料，教学交付不解锁收藏。 |
| F03／F04／F11／F15 | 读订单、持物与晾架状态，操纵两位玩家往返纸院与印坊 | HUD 读单份订单、倒计时、得分、两名玩家各一件持物及 A/B 独立槽状态。场内标识跟随对应工位或角色。 | 02 v02、06 v02 各一张，场景底图 v01 一张 | 替换时间及持物后，玩家编号仍与角色对应。检查 720p、1080p 与 1280×800，下半屏互不遮挡，双槽进度可区分。 |
| F12 | 暂停、继续，打开设置或说明，重开或离场 | 暂停时屏蔽背景输入，冻结局时、加工及两槽计时。确认重开后清场再计时，确认离开返回选关，保留此前已结算记录。 | 03 v02 一张、确认状态 v02 两张。操作说明复用 06 v02。 | 暂停 10 秒后取消确认并继续，核对原进度。确认重开后检查双手和双槽均空。 |
| F13／F14／F18 | 在图鉴查看已收录的组合并返回 | 读取四动物白名单，两位不同动物的稳定 ID 排序后组合；正式轮次有交付并结算才收录。总数、锁态和详情读取同组存档数据。 | 04、05 v02 各一张，复用一张现有结算票面 | 交换两人位置不重复计数，教学和中途离开不解锁。示例中只有泡泡 × 墨墩可进入详情，回图鉴仍显示 1/6。 |

图鉴沿用现有六个稳定组合键。示例查看的是 `modun_paopao`。另外五格保留锁态，本批新增正式组合票 0 张。[四动物与组合合同](../../Docs/设定同步_v01_20261120/当前角色与组合合同_v01_20261120.json) · [F01—F20 对齐表](../../Docs/开发颗粒度对齐表_v03_20261120.md) · [首关 UI 接口](../UI_首关_v01_20261113/ui_contract.json)
