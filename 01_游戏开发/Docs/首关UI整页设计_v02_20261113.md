## 视觉确认与验收边界

本轮先确认整页布局与纸艺质感。参考图中的旧标题、多订单和多张持物不是当前规则；画面装饰库存不定义真实槽容量。HUD 已作印台单张、刷子提示与取消旧压纸装置的局部修正。票面黑墨／朱印颜色仍为展示示意，未交付可独立切换的图层。

新增五页沿用前两页的厚纸框、金色压边、人物与配色；原 01／02 图片文件保持不变。暂停设置图是一张整页排布，不是多张页面缩略拼贴。选角只展示两名初始角色与准备状态，收藏只展示首款，不扩充六角色技能或十五款内容。

后续拆件以最终采用的画面为准，再检查面板、按钮、图标的透明边缘、有效像素、统一尺寸与切片安全区。Unity 灰盒由另一位开发者维护；本批没有运行其工程，也不沿用 v01 网页的 103 项检查作为本轮图像或 Unity 验收结论。
