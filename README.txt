当前游戏方向（2026-11-20）
名称：交子赶工记。宣传语：交个纸友，一起开工。
题材：财神府纸币司的四钱灵进入北宋益州忆境，通过交子、造纸与印刷理解和传递钱币文化；双人合作赶工。
流程：室外造纸 → 贯通室内印刷 → 盖印 → 交付。
美术：高角度俯视、接近正交；古装、纸艺折面、宽方大头、短身短肢、可爱但轮廓清楚。
角色：泡泡、水獭女；递蕉、金丝猴男；墨墩、大熊猫女；烘栗、小熊猫男。仅四动物，无人类角色；墨大嘴历史暂停。
收藏：两位不同动物组合，不分左右，四选二共6款。历史纸团印桃首票不计入新收藏。
开发状态：已存在场景、旧人类绑骨模型、道具、UI图片及旧开场；本轮统一设定不代表这些资产已经替换为四动物。Unity灰盒由另一位开发者维护，需对接其工程、提交和测试。
制作路线：模型制作工具／Blender制作资源后导入Unity；不使用UE。
