# F01 开场机关书：衔接与车轮优化 v11

日期：2026-11-13。基于 v10 另存，保留六章 56 秒、暖色纸艺、正常双页立体书、用户指定人物、华文楷体字幕及交子背景故事。用户本轮新增“轮胎也要优化”，纳入第一章推车。此交付是 F01 的开场影片与可检查源，不代表 Unity 灰盒已接入。

## 玩家行为、程序产出

玩家连续观看开场，可暂停、跳过、重播、静音。影片先讲铁钱不便、纸券与官办交子、买卖用途，再揭示双人纸艺作坊和首张组合交子；字幕不出现角色姓名。

| 优化项 | v11 行为 |
|---|---|
| 人物递物 | 五处凭券、包裹、纸张、交子交接使用手掌世界坐标；交接结束后物品随持有者移动 |
| 纸偶脚步 | 按各姿态鞋子位置分别裁切，避免旧版统一分界切开鞋子；步相随位移，抬脚、身体起伏与缩放一致，启停渐缓 |
| 作坊动作 | 女孩全程使用同一伸手姿态，不在印刷前后突然换脸或衣摆；纸从手中落台、加工、取走；手掌与印章共用位置关系；印章放下后在返回人物后方 |
| 环境 | 路人分别启停；落叶分前后层，近处叶片沿两侧飘落；河纹沿弯曲水路移动；槽内涟漪分批扩散 |
| 车轮 | 复用原车唯一外轮缘，仅内部轮辐转动；修正旋转中心，轮毂固定在轴心；向右推车对应屏幕顺时针滚动，转角由位移除以可见半径得到；接地阴影跟随车轮 |
| 书页收展 | 分开固定地面、立起景片与人物；动态云局部遮罩按当前帧补全真实轮廓，预留 24 px 移动余量，避免云边被切成阶梯；收展衔接和曲面翻页由 `composition.js` / `page-turn.js` 控制 |

程序产出：1 段 1920×1080 / 24 fps / 56 秒 H.264 + AAC 成片，1 个播放器，1 个可拖动时间的分层源页面，6 个运行时动画 JS 模块，渲染、音轨、编码与核验脚本。1344 帧可由脚本重新生成。

## 接口要求

- 源页面等待 `window.ready` 后调用 `renderFrame(seconds)`，0—56 秒，支持任意顺序拖动时间，结果应一致。
- 播放器 `intro-finished`：`detail={reason:'ended'|'skipped',runId,version:'v11'}`。同一轮结束只回调一次。浏览器首次需点击启动有声播放；实际 Unity 宿主负责自动播放和结束后跳转。
- `CharacterMotion.draw(ctx,chapter,localSeconds,{background:false,occlusion:false})` 可输出不带工位遮挡的纸偶，供收展合成使用；`handPoint(...)` 与 `debug.contacts` 供接触检查。
- `CartMotion.init()` 载入原道具图谱；`CartMotion.draw(ctx,1295,625,travel)` 在默认第一章位置绘制推车，内部加位移。不要在外部再次加 `travel`，也不要再绘制旧 `props.wheel`。
- `CartMotion.getState(travel)` 返回两轮中心、半径、转角、轮毂角和接地点；`angle=travel/radius`，停止移动即停止转动。原车图为侧面图，两只可见车轮保持同一近侧平面。
- `EnvironmentMotion.getWalkerStates(chapter,t)` 返回每个行人的位置、距离、步相和行走强度；停止后位置及步相固定。
- `Ambience.drawWater` 单独输出水层；`drawLeaves(ctx,chapter,t,'all'|'back'|'front')` 输出指定叶层；`drawUnder` 为水+后叶，`drawOver` 为前叶。
- 继续采用固定镜头 2.5D 图层、纸偶关节和纸页曲面。此源不是完整可旋转三维模型，不是 Unity 工程；Unity 接入需对接另一位开发者的工程与提交版本。

## 验收情景与记录

1. 第一章车向右走，两轮内辐条顺时针旋转；扣除车整体平移后，外轮缘和轮毂稳定，无第二重轮缘、无矩形车板随轮旋转。轮轴高度不随转角跳动。
2. 五段交接前后，物件边界与相应手掌接触；顾客后退时纸随手走。盖印阶段手柄与手掌接触，42 秒朱印与盖印声对齐。
3. 检查女孩 38—44 秒进入印台、盖印、返回，避免换姿态硬切、台面遮脸、已放下印章盖住经过的人物；检查 NPC 行走时鞋子完整。
4. 六名路人移动距离与步相同步，停止时不继续踏步。水纹在河道/纸槽内，落叶不反复穿过主角面部。
5. 逐章检查收起与翻页关键帧；`收展连续性核验_v11.json` 的 16 项检查通过。对连续 24 fps 输出的像素变化检查仅用于发现大范围跳变，不代替美术判断。
6. `动作与字体核验_v11.json` 的六章完整画面、37 项独立图层检查、实际字体载入与翻页几何检查通过，覆盖独立人物/环境、水面边界、确定性拖动、递物及车轮。`播放器核验_v11.json` 的六项检查通过，包含真实 MP4 播放、暂停、跳过只回调一次、重播后自然结束与停止播放。
7. 1344 帧已编码为 56 秒 1920×1080 / 24 fps 成片，完整解码通过；`媒体核验_v11.json` 记录实际帧数、音视频流信息和成片 SHA-256。美术满意度以用户反馈为准；本轮没有真人听音或 Unity 联调验收。
