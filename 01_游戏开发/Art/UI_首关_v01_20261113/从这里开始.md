# 《交子赶工记》首关 UI v01

2026-11-13。双击 [index.html](index.html) 打开界面演示。也可以由本地静态服务器打开此目录。网页离线引用同目录资源，不需要登录。

本批包含首关标题与地图入口、纸团／印桃双人选角、教学与局内 HUD、暂停设置、结算和首款收藏。通过页面按钮或键盘浏览流程，Tab／Shift+Tab 切换焦点，Enter／Space 操作焦点按钮，Esc 返回或暂停。选角使用 P1 A／D、F 确认；P2 左／右方向键、主键盘 / 确认，再按确认取消。

这是界面与状态演示，场景图来自当前 Blender 模型渲染；没有在网页内运行 Unity。演示操作入口与真实游戏操作应按页面提示区分。网页本地记录只供 UI 演示，不与正式游戏进度互通。

采用单件持物、同时一单、双槽晾纸、正式轮次 180 秒。订单依次为 1／1／2 张；每交一张 +10，整单额外 +10。教学不计正式分数；正式结算至少交一张才解锁首款交子。

正式 Unity 的 UI Toolkit 布局、游戏状态绑定、输入、音频和存档由另一位开发者接入。资源与演示交付不代表该工程运行验收已经通过。

本批网页 **103／103 项浏览器检查通过**，被测文件哈希、窗口尺寸、检查内容和限制见核验报告。本轮未运行 Unity 工程；网页检查不能替代引擎联调与完整双人试玩。

页面底部“界面预览”可展开六个页面入口，以及局内的订单交付、持物、A／B 晾纸槽和拒绝提示等模拟按钮。这些按钮供设计核对使用，不属于正式游戏 HUD。预览“结算”会生成示例成绩并写入本浏览器的独立预览记录；它不是正式游戏存档。

设置中的音乐试听复用已有开场配乐，并非本批新制作的最终游戏配乐。“预览画布宽度”调整页面最大宽度，不改变系统窗口分辨率；全屏按钮请求浏览器全屏，能否进入取决于浏览器支持。总音量、音乐与音效滑条分别作用于本网页试听和按钮提示声。
