# 首关工位触台适配

版本：station_fit_v01_20261111。适配对象是已加载的场景 v05 或角色道具整合 v01；原文件保持不变。

本包提供 `adapt_stations.apply()` 和冻结尺寸配置，不另导完整关卡。主整合任务负责输出整合 v02、场景 GLB、六工位独立 GLB 和最终预览。

## 实测依据与冻结尺寸

- 两角色保留 1.2 m 身高、短臂风格和骨长。角色代理实测 Work 实际掌底为 Z=0.350 m，前向 Y约-0.273 m；这不是用骨心替代掌面。
- 裸台顶 0.330 m，薄版或垫 0.014 m，纸厚 0.006 m，实际纸面接触高度 0.350 m。台面纸与雕版整体旋转 Z=90°；纸张仍为 0.42×0.60 m，未缩放。
- 根点在近侧台沿外 0.240 m；躯干核心代理 r=0.220 m、skin=0.015 m，名义余量 0.005 m。它不包住全部鞋尖、衣摆、头发或帽子，不能把此代理检查等同于完整网格无穿插。
- 桌腿保持落地，前后腿、裙板与横撑后缩；台板也有独立 Box proxy，不以忽略台板碰撞为由将角色放入台体。

抄纸槽只降低槽体及操作侧槽唇；原尺寸帘框在槽上方，手接近侧横杆顶面 Z=0.350 m，湿纸输出位独立为 Z=0.352 m。本工位的加工接触面是帘框，不把输出湿纸当作同时加工的第二件物品。操作侧 +Y 槽板及纸层缝再向槽内退 0.040 m，板外脸从 Y=0.410 改为 0.370，给实际 Work 腰部留空；帘杆接触线 Y=0.377、站位 Y=0.650 和两侧柱脚占地不变。槽体碰撞代理拆为内退核心、操作侧挡板、远侧挡板与两侧窄条，不再用整块上沿 Box 填满敞口槽面。

晾架保留高竹架和绳扎轮廓，外宽增到 2.40 m，两槽和两站位相距 1.30 m。两张原尺寸纸放在 30° 斜托，近缘 Z=0.350、远缘约 0.650 m；近侧有真实水平接纸条，宽0.48、深0.07、顶Z=0.350。纸的近缘在掌接触线后0.03 m，使掌面接触水平条而不是强行穿进斜纸。旧高位夹子的操作动画不在本轮范围，没有增加新工序。

交付窗只降低下柜、柜台和接收托盘；上方木构、屋檐、卷轴纸匾不做整体缩放。接收目标仍只消耗交付票，托盘不成为暂存槽，回执不成为背包物料。

## 程序与美术接口

- 原有六个 station 根保留位置。每站仍一个物料锚点，晾架 A/B 两个，共七个；坐标已经为触台修订，不能继续使用 v01 的旧高度。
- `station_*__standing_main` 或 `standing_A/B` 是角色根站位；`interaction_*` 是候选交互点，两者分开。
- `station_*__work_frame_main` 或 `work_frame_A/B` 给出接触参考坐标系；`station_*__tool_Grip_L/R_main`（晾架为A/B后缀）是实际掌接触目标，role=`work_contact`。左右名按角色正前方定义。
- 返回报告的 `stations[].work_frames[]` 包含局部/世界站位、朝向、实际接触高度、左右目标和允许接触的实物对象名；`colliders[]` 明示 Box 的中心与尺寸。场景里同名 proxy 是非渲染 Empty 元数据，不冒充已经生成 Unity Collider 组件。
- `create_contact_demo_sheets=true` 只为检视添加每个目标槽的一张纸，并标记 art_demonstration / not_gameplay_initial_state；真实开局的空槽状态由规则层创建，不能把本包演示物当作初始库存。
- 道具 GLB 根先明确切换为 XYZ 旋转模式再赋 Euler，避免 glTF 的 Quaternion 模式吞掉纸/雕版的旋转。

## 验证与边界

[工位接口几何核验](工位接口几何核验_v01_20261111.json) 已实际打开整合 v01、执行适配并对 evaluated mesh 三角 BVH 求最近点：14 个左右接触目标全部位于指定真实工件面 1 mm 内。角色 Armature 世界矩阵、Rest 骨矩阵、Action 名前后完全一致；源整合 v01 BLEND 的 SHA-256 未变。

这份报告只证明工位接口和实物面相符。两名角色在七站、全部 Work 帧的非手部网格碰撞由主整合/独立审查另验，当前不能据此宣称所有身体穿插已解决。Unity实时交互、碰撞控制器和双人180秒流程仍由外部程序工程验收。

## 执行

在 Blender 打开源场景后把脚本目录加入 sys.path，再调用 `import adapt_stations; report = adapt_stations.apply()`。该函数不保存源场景、不改角色、不渲染、不导出。一次加载只允许执行一次；重复构建应重新打开源场景。

冻结参数在 `Scripts/Blender/首关工位适配_v01_20261111/适配尺寸配置_v01_20261111.json`；它记录本轮已确认剖面，不承诺任意改值都能自动满足接触约束。几何、接触和角色姿势须共同复验。

`smoke_apply.py` 生成 [工位适配报告](工位适配报告_v01_20261111.json)；`validate_contacts.py` 生成真实接触面与源文件完整性证据。二者均不另存完整场景。
