# F01 开场机关书 v08：效果图分层合成
更新：2026-11-13。目录沿用本批开始日期 20261112，修正版文件及本说明以 11-13 为准。

## 本次交付与准确状态
56 秒、六章、1920×1080、24 fps 的 2.5D 动态预览。以 v06 六张游戏画风效果图为主，保留原图人物，新增空书底图与无人物场景底层，最后一章使用 11-13 的铺面透视修正版。Canvas 源时间轴可逐帧拖动，MP4 用于直接审看。

这是完整长度的动态分镜预览，不是可任意旋转的三维机关书，也不是已接入 Unity 的游戏开场。人物是原图纸卡轻摆；场景撑起为分层投影；尚没有逐肢动作、手臂交付动作和真实纸机关运动学。第五章的票面显现是工序的叙事示意，不能作为五工位程序状态或完整操作演示。画面效果与节奏待用户审看，不把自动检查通过当作美术验收。

此前 v07 Blender 工程保留为结构试验，本版本不依赖它，不把稀疏三维试验作为最终效果。

## 复现与核验边界
1. Node 24 执行 render.mjs --preview，检查六章与过渡采样。
2. Node 24 执行 render.mjs，生成 1344 张帧到 Scripts 同目录 work/frames（忽略入 Git）。
3. 使用带 NumPy 的 Python 执行 create_audio.py。当前使用 Blender 5.3 的 Python 运行时，仅用于音频合成。
4. PowerShell 执行 encode.ps1，合成并全片解码。
5. Node 24 执行 render.mjs --qa，检查实际成片在离线播放器的元数据、播放推进、暂停、重复跳过和重播后的自然结束。
6. 另存 SHA-256、实际流信息与验收记录；只提交本次 Art、Scripts、Docs 的文件。

主机有声解码状态与波形统计可自动检查，不等于真人听感验收；本版没有旁白。Unity 的工程、提交与真实联调结果须由另一开发者提供。本地没有冒充其工程。
