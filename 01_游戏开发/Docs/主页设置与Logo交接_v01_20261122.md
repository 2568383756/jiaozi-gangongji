# 交子铺主页、设置与 Logo 交接

本次评审使用交子铺主页 v02、透明字标 v08 和设置页 v01。前两张对应 2026-11-22 的主页配色、台面透视与铜钱位置修订。玩家看到的整页、独立字标、柜台底图和历史稿均可从[美术目录](../Art/主页设置与Logo_几何剪纸_v01_20261122/从这里开始.md)打开。当前交付为静态 PNG，以下交互待外部 Unity 工程接入与测试。

## F01　从交子铺入坊

**玩家行为。** 在柜台正面选择「开始营业」「继续」「图鉴」或「设置」。「开始营业」进入选关和双人选角，两人分别选好不同动物并确认后开局。「继续」读取已结算的有效进度进入选关，再经过双人选角。「图鉴」进入组合交子收藏。

**美术与接口。** 主页整页 1 张复用方形透明 Logo 1 张，另附柜台底图 1 张。将字标按原比例居中摆在柜台上方；整页预览已合成字标，运行时若需单独挂载字标，应改用底图。沿用正面无角色的交子铺构图，柜台中央留空，物件接触阴影贴近台面。继续入口的灰化对应新档样例，激活、焦点和可点击区域由存档状态和导航代码驱动。[主页 v02](../Art/主页设置与Logo_几何剪纸_v01_20261122/02_交子铺台面_主页_配色透视修正_v02_20261122.png) · [Logo v08](../Art/主页设置与Logo_几何剪纸_v01_20261122/01_交子赶工记_方形Logo_铜钱靠字_v08_20261122.png) · [柜台底图 v02](../Art/主页设置与Logo_几何剪纸_v01_20261122/分层/主页柜台底图_v02_20261122.png)

**程序验收。** 无有效进度时，「继续」置灰且无法触发；有有效进度时，进入选关并完成双人确认。设置可以从主页打开并返回。验收时检查所有四个入口的导航和实际触发结果。[F01—F20 对齐表](开发颗粒度对齐表_v03_20261120.md) · [UI 导航合同](../Art/UI_首关_v01_20261113/ui_contract.json) · [当前四动物合同](设定同步_v01_20261120/当前角色与组合合同_v01_20261120.json)

## F12　设置与返回

**美术资产。** 红棕剪纸设置整页 1 张沿用 v01。画面上的百分比与分辨率是排版样例，运行时由设置快照填入。[游戏设置 v01](../Art/主页设置与Logo_几何剪纸_v01_20261122/03_游戏设置_红棕剪纸_UI整页_v01_20261122.png)

| 玩家操作 | 程序接口与验收 |
| --- | --- |
| 调整总音量、音乐、音效 | 三条滑条对应 `masterVolume`、`musicVolume`、`sfxVolume`，值域 0—1。显示值与设置快照一致。 |
| 调整显示或查看操作说明 | `fullscreen` 与 `windowResolution` 读取目标平台支持值。`showControls` 展示既有双人键位。 |
| 选择「保存」或「取消」 | 保存通过 `RequestSettingsApply` 应用合法快照。取消时保留打开页面前的值。两条路径均返回打开设置的页面。 |
| 在暂停中修改设置 | 保持局时、工位加工、两槽晾纸与扇风冻结，阻断背景输入。暂停 10 秒再退出设置，仍停在暂停菜单，回合与两槽进度保持原值。 |

双人键位与首关设置的原始接口详见[交接摘要 v02](新窗口交接_游戏开发_v02_20261120.md)与[首关整页 UI 交接](首关UI整页设计_v02_20261113.md)。

## F14　有效进度与设置持久化

F14 复用上述两页，美术新增 0 张。「继续」只读取有效已结算记录，局内订单、剩余时间、手持物和晾架进度不进入恢复流程。「保存」只应用设置。外部工程需验证新档、正常记录、损坏记录以及应用设置后重启四种情景；已取消的设置须保持原值。[首关存档交接](首关UI交接_v01_20261113.md)

## 美术核对

在主页实际显示尺寸下检查「交子赶工记」五字与方孔是否清楚、铜钱是否靠近「交」字、左上矩形是否已移除。台面上的钱与字标上的钱分别按各自所在平面表现；纸张、印章、砚台与账册须与台面共用视角。首页配色以暖木与米白为主，主按钮保留朱红。设置样稿的验收重点是操作文字和选项状态可读。[修订与参考图索引](../Art/主页设置与Logo_几何剪纸_v01_20261122/从这里开始.md) · [UI 统一规范 v03](UI统一设计规范_v03_20261122.md)
