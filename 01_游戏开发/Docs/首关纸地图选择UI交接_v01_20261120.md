首关沿用“开张第一单”，来源为[玩法与开发规格](玩法与开发规格.md)的首关入口流程，以及[完整游戏设计文档](参考文档_20261110/交子赶工记完整游戏设计文档.md)中的首关表。这里仅沿用已有首关名称，不恢复这些历史文档中的人类阵容或旧扩关范围。

当前流程与范围以[开发颗粒度对齐表 v03](开发颗粒度对齐表_v03_20261120.md)、[世界观角色与技能统一设定 v01](设定同步_v01_20261120/世界观角色与技能统一设定_v01_20261120.md)为准：先完成第一关；F01 进入首关不能越过 F02 选角；F17 后续普通关尚待确认，本轮新增 0。抄纸、晾干、印刷、盖印、交付是同一关内的连续工序，不拆成多个关卡。旧“三普通关＋一 Boss”不自动恢复。

地图独立重新设计，以宋代街坊木构、交子铺、商贸幌子、纸币纹样作为题材元素，采用桌面展开纸地图、折叠山水、纸艺建筑、竖签和连贯路径，以明亮米灰、青绿、赭色统一纸张与手绘质感。它不是旧地图或首关场景的同比例缩略图，不照搬原场景布局、工位位置或旧场景模型。

仅“开张第一单”是正式可进入的首关节点，其他建筑、路径与山水均为环境装饰，不暗示新增可玩关卡、解锁门槛或挑战模式。地图概念中的建筑位置不作为第一关实际碰撞、行走路线或工作台布局的依据。

成图以全新两层宋风木构交子铺为主体，纸币长卷边饰围合河流、纸桥、远景小铺与城门。仅主铺具有“01 开张第一单”题签，远景小铺和城门没有关卡标签或可进入标识。纸币只绘装饰性抽象纹样，不作为六组合正式交子票面，也不作为历史票据复原。

画面文字为“选择关卡”“开张第一单”“双人合作”“双人·180秒”及必要操作；180 秒沿用现有正式轮次时长，不增加地图倒计时。主按钮为“选择搭档”，通向 F02 双人选角，不直接加载局内。P1 圆标、P2 菱标表示双人玩法，不表示已选动物或已准备。无人类角色、人像票面，不加入付费、体力、商城、挑战、奖励等未确认系统。

地图上的纸艺建筑和折叠山水属于整页生成式视觉，不等于已制作独立场景模型、导航节点组件或可运行关卡。图中文字与节点状态需在正式 UI 中动态呈现，不将示例直接作为已运行功能。
