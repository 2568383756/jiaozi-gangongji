## 使用口径

- Blender XY 为地面、Z 向上，1 单位 = 1 米；GLB 导出为 Y 向上。角色名义身高 1.2 m，纸张 .42 × .60 m。
- 裸台顶 .330 m，薄版／纸垫 .014 m，纸体 .006 m，工作接触面 .350 m；站位在台沿外 .240 m。固定工具泊位及晾架、交付窗口的构造分别适配，不能统一缩放整个场景。
- 双槽晾架宽 2.4 m、槽间距 1.3 m，纸张置于低位斜托。手接触前方水平接纸条，高处夹子与装饰并非本动作的接触目标。
- 新工作面、21 个纸／交互／站位接口及碰撞参考以本版为准。原 v05 的植物、外景和主相机保持；原 .65 m 台高只作历史对照。
- 模型里放置的纸态是美术检查样本，不是开局库存。所有权、进度、拿放、计时、计分和拒收均由游戏程序维护。
- 新手保持同一主体网格与原角色骨架，局部手部拓扑和掌面姿态以角色 v02 文件为准。纸根零挂 HoldPoint；不要直接复制 v01 的备用 PalmCenter 数值。

## 核验方法与限制

独立审计用实际变形后的蒙皮三角与工位三角。AABB 只用于快速排除；判定穿插使用三角 BVH。故意接触的手部与非手身体分别检查：掌面探针必须靠近该工位明确允许的实际表面，分别检查两脚高度；两人在晾架 A／B 的两种分配也单独检查。精确方法、采样帧和结果以 JSON 为准。

最终文件的场景接触检查 44／44 通过，保存与静态 GLB 回导检查 52／52 通过。两角色 314 帧的[新手独立审计](../../Scripts/Blender/触台比例核验_v01_20261111/新手最终独立核验_v01_20261111.json)检查了真实持纸、手掌和新袖衬。原模型宽袖与下颌仍有局部交叠，已在[来源核查](../../Scripts/Blender/触台比例核验_v01_20261111/原袖下颌接触来源核查_v01_20261111.json)单独记录；不将本批描述为全身所有自碰撞均消除。

本机进行了 Blender 后台制作、渲染与导出回导。未重载前台 Blender GUI，也未在另一位开发者的 Unity 工程运行。采样网格检查不代替运行时碰撞、连续运动、动画切换和完整三分钟双人试玩；Work 接触样本也不代替全部专用工具动作。

印台及双槽晾架近景采用剖视展示，渲染时临时隐藏会挡镜头的墙檐与附墙装饰；角色、纸张和工位全部保留。完整场景文件、GLB 和游戏机位保留建筑，具体近景隐藏集合记录在整合核验 JSON。

## 重建

完整根目录为 `E:/codex-jiaozi/交子赶工记_项目总库_20261104`。先准备角色 v02，再用 Blender 5.3 运行本批[脚本目录](../../Scripts/Blender/首关整合_v02_20261111/)中的：

1. `build_contact_assembly.py -- --baseline`：旧版同机位对照。
2. `build_contact_assembly.py -- --render`：重建、导出和渲染新版。
3. `audit_contact_mesh.py`：实际接触／身体网格检查。
4. `validate_contact_delivery.py`：保存后复开与静态 GLB 回导。
5. `verify_batch.py`：用普通 Python 核对本批文件与链接；加入 `--index` 时再核对 Git 索引。

渲染使用 Cycles CUDA、Standard／None、曝光 0，保留鲜明暖木、金黄银杏和蓝瓦配色。
