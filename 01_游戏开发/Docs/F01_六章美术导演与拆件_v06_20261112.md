## 1. 制作顺序：先看到故事，再拆成可动的纸

1. **先做六张AI章效果图。** 每张都是完整镜头中实际展开的立体书：封面和页块、中缝、从纸页立起的景片及折脚均清楚可见，不能交成平面插画。每章表现一个最有叙事意义的瞬间；六图并排比较镜头、书型、人物比例、纸材与光色。效果图不是图标清单、角色排队照，也不是完成的可动画资产。
2. **按六张实际输出确定拆件，再制作素材。** 从效果图确定主次、前后层、接地位置和遮挡关系；独立制作无烘焙透视的分层正视素材，补全被遮挡部分。移动手臂、票券、担子、工位工具、墙面和屋顶分别处理。整张效果图或带透视的局部裁图不能直接贴成一块竖板充当场景。
3. **最后做3D与动作。** 先验证同一本书的翻页、两个相邻景片收合和一次手间交接，再按已定稿六图搭建章节。效果图里的每个动件必须有锚点和运动职责；不能用增加对象数代替动作、接触和画面质量。

阶段计划产出为：六张章效果PNG及各自提示词、六份拆件清单与对应透明素材包、六个章场景集合及一个总开场Blender工程。先完成整组六图与一致性检查，按实际输出继续素材阶段；纳入已有反馈和制作自检，不增设用户必须逐张审批的门槛。后续素材件数由实际效果图拆解登记，不能因计划表已列出就视为完成；不跳过素材阶段直接批量搭建所有3D。

## 2. 六章共同的美术准则

### 2.1 同一册书、同一镜头、同一地面

六张完整镜头均是一册实际展开的正常双页立体书，封面、页块、中缝、前后约4—6层薄轮廓景片和V折脚清楚。前景边沿、中景人物／柜台、后景铺面／树冠分层立起，层与层之间有能看见的空气，轮廓间保留背景留白；不是厚木房子、实体瓦片和模型人物堆在书上。街道、水纹与低矮景物彩绘延续到平面纸页，与立起纸片共同构成场景。

不另放厚台座，不把全部内容画成平插画，也不只竖起两片墙形成盒状隔间。后续3D仅建立必要纸片厚度、V折／平行折脚及少量可接触的纸折台面，不要求完整复杂房屋。影片计划正常翻页、景片收合与展开，点击播放后连续演出。

六张效果图使用同一机位模板：从书的前上方看入，约35°俯角、轻微偏右，近正交的长焦视感；避免广角夸张和严格顶视。后续3D先以长焦约85—100mm的构图目标匹配效果图，再冻结一套相机参数，不让各章自行变化焦段。以上是构图计划，不是已生成的相机数值。停留画面保持大展示，翻页只做必要的取景调整。

两页共用接地高度，角色脚底、桌腿、门槛、担子落点与纸景折脚都落在同一纸面。房屋透视、屋檐方向和地砖走向服从这一镜头。景片不是都正脸朝观众：人物面向正在交易或协作的对象，桌面朝向可操作的一侧，屋檐沿街巷或院落布置。

### 2.2 以情境建立主次

每章只设一个主动作和一个最清楚的接触点。画面先让人看出“谁需要做什么、什么阻碍了他、另一方怎样接应”，再看建筑和装饰。六图分别抓住：肩上沉重的担子、柜台交接的小券、官办窗口发出的新券、换到手的一包茶、两工匠接力的一张纸、首票跨过交付窗口。

禁止巨型悬浮铁钱、巨型悬浮券、展示台式左右对称摆拍、沿书页排一串孤立图标。钱在筐／袋／柜台里，纸券在手／纸托／台面上；移动时有承托、接触、交接和停留。道具尺寸服务于人物的手、肩和台面，不为醒目而放大成纪念碑。第6章通过前景位置与朝向展示票面，不把票放大到超过工匠肩宽。

前景承载动作或引导视线，中景形成工作空间，后景只解释地点。每章建筑须有不同的功能轮廓：街巷转角、开口铺户、较规整的官办柜台、茶棚与布店、贯通院坊、交付窗口。第5—6章可复用同一作坊保证连续性，其余不要复制同一屋形排满六页。不自动添加三角形山、左右各一棵树、悬空云朵作为统一背景模板；确需远景时采用低矮、非对称的剪纸轮廓，服从故事地点。

### 2.3 温暖纸艺与角色锁定

修订03保留已经认可的4—6层薄片、V折与彩绘地面结构，只调整画风：暖金木色、青蓝瓦色、清爽大色块与简洁描线，人物采用与游戏一致的大头、短身、短肢纸艺比例。减少修订02的写实细线和成人写实比例；建筑装饰也同步简化。两位正式工匠仍严格依原始参考，不以风格统一为由重设计帽发、服饰或五官。

米白纸、浅赭、杏金、克制的黛青和朱砂为共同色系。全场景约4—6层前后纸景；单件内部可有少量色纸叠层，不能把单件厚叠变成实体模型。纸纤维和印绘线条克制，切边薄、V折可见，阴影主要说明纸片间距。木纹、瓦片、窗框以印绘或轻薄附层表现，不逐块雕出厚木瓦。不用塑料、黏土、泡沫厚块、强高光、全场倒角或密集噪点；树冠也是带空隙的轮廓薄片。

游戏段只使用已确认的两位工匠，**原始帽形／发式、五官、服色、衣饰、头身比、肢体比例和身份轮廓不改**。改变的是站位、视线、手臂姿态和纸片层级，不另设计一对“更像宋代”的新主角。生成时同时带入两张正式原图作身份约束；不得以v02—v05的AI重绘自动替代原始身份基准。角色原图如有旧姓名标注，不带入画面。

前四章的行商、铺户人员、官办经办者和摊贩只作匿名历史情境人物，不新增可选角色、名字、职业技能或人物设定。第5章才出现游戏主角；第6章才清楚展示双人肖像组合票。背景人物的数量和细节低于主体，不让匿名人物抢走游戏角色识别。

### 2.4 所有文字留在书外

章题、历史说明、两行字幕、游戏标题全部在书外画面叠加，统一位于不遮书的字幕安全区。AI效果图不生成文字；书封、页码、屋匾、钱文、券题、工位标签均不出现可读文字。官办阶段由场景与书外“益州交子务”字幕说明，不能靠页上大牌匾替代情境。

钱券可有非可读刻线、边框、木刻纹样和朱色印记；游戏票保留两位原始角色的图形识别。正式票面源图若含文字，后续只在另存的v06工作层分离处理文字层，不改历史原图，不为效果图捏造新文案。

## 4. 逐章导演与拆件计划

以下数量为**单章计划可见实例**，不等于独立素材文件数或已完成数量。复用角色／建筑须登记来源；一个角色的躯干与两段前臂只是拆件，不能在画面中变成多个重复人物。每章先产出一张完整AI效果图，再按本表拆件。

### CH01 铁钱难行：货物能卖，钱却难搬

玩家观看负重故事，无章内操作。计划程序产出为`CH01`章节集合、`load_shift`负重换肩动作及本章折景收合段；按第7节CH01路径保存，版本`v06_20261112`。

**主体与关键瞬间。** 已获结构方向认可的修订02首章把负重行商放在中前景：两筐铁钱压住肩担，人物弯身迈步，旁侧推货车的商贩提供街市买卖情境。主动作仍是“身体撑住钱的重量”，不正对镜头展示大硬币。后续动作可在此姿态基础上做短步、停步扶担与换肩；不能因旧计划写过另一种筐内容而把已经生成的新主图误标为失败。

**前中后景。** 修订02以纸页上的石路／水纹延续前景，果篮、草叶等低轮廓薄片围出前缘；中景是负重行商与推货车商贩；后景是高低错落的铺面、桥和街中人群，树冠作为带留白的高层景片。拆件以4—6个主要深度层组织，不为每个印绘窗框再建立完整实体房间。

**因果动作计划。** 行商短步前移→负重筐有小幅滞后摆动→停步扶担换肩→身体稍恢复。钱不会自己升空；无需弹跳或夸张压弯身体。用衣摆和筐绳的小幅跟随增添生活感。

### CH02 纸券初生：交存钱，接回轻便凭券

玩家观看交存与取券的因果，无章内操作。计划程序产出为`CH02`章节集合、`cash_to_receipt`动作及钱袋／纸券归属切换；按第7节CH02路径保存，版本`v06_20261112`。

**主体与关键瞬间。** 同一匿名行商来到铺户柜台，钱袋已放在柜台内侧。铺户人员从自己的票据托中抽出一张小券，越过台沿递向行商张开的手。效果图表现两人对视及纸券将要交到手的时刻，券的大小可单手接住。

**前中后景。** 前景可见空下来的担子与行商的站位；中景是两人和柜台，台面留清楚的交接通道；后景用半开侧墙、储物格、窗棂说明这是能存钱的铺户。不是两个人站在一张悬浮券两侧。

**因果动作计划。** 行商把钱袋放入柜台接收区→铺户收妥→从自己的票据托取券→券从铺户手切换到行商手→行商带券离台。钱袋与券的动作有先后，不表现任意白纸自行变钱。取钱与转让用途由既有字幕说明，不额外挤入第二笔交易。

**F01验收情景。** 停在交接前后两帧可以明确区分钱已交存、券正在被接走；台面上的钱袋和手中的小券形成原因与结果；无巨券、无无接触漂移，券未使用游戏双人肖像。

### CH03 官办交子：从铺户凭券走向官办发行

玩家识别官办发行新阶段，无章内操作。计划程序产出为`CH03`章节集合、`official_issue`递券动作和独立官办券源；按第7节CH03路径保存，版本`v06_20261112`。

**主体与关键瞬间。** 官办场所里，经办者从整理好的新券托中取出一张，隔着较规整的柜台交给来领券的人。效果图抓住“新券从官办柜台发出”的瞬间；人物仍是日常办事姿态，不出现宣读诏令的舞台式站队。

**前中后景。** 前景是领券者的手和柜台外侧；中景是经办者、纸托与正在交接的小券；后景以较规整的柱列、成组格柜和深檐形成官办空间。建筑从结构、秩序和色彩与铺户区分，不靠巨匾或皇家符号。

**因果动作计划。** 经办者核看无可读字的记录页→从官办新券托取一张→递至来者手中→手收回，新券留在领取者手中。官办券是独立批次，民间券不在镜头里原地“升级”。这些是解释发行场景的纸艺动作，不声称复原史实办理手续。

| 官办柜台1、新券托1、记录页1、活动官办券1、固定整理纸组1 | `OFFICIAL_NOTE_SOURCE`独立于CH02券源；券接触后唯一归属转移；固定纸组不随动作弹飞 |

**F01验收情景。** 与CH02并排可以分辨民间铺户和官办场所；看动作可知纸券由柜台人员发出，不是私券被随意盖印；书内无可读文字，官办身份由既有书外字幕明确。

### CH04 一纸通市：纸券换到生活里的东西

玩家观看一次买卖，并经字幕进入架空世界，无章内操作。计划程序产出为`CH04`章节集合、`pay_then_receive`券／货顺序交接及低幅度卷布次动作；按第7节CH04路径保存，版本`v06_20261112`。

**主体与关键瞬间。** 顾客在茶摊买茶，茶商接过一张小券后，将一包茶递回。右后方布店的人正在收齐一卷布，形成同一条街上的另一门生意。效果图选取“茶包落入顾客手中”的瞬间：钱券已在摊主的接收托里，不让顾客同时抱着券和商品。

**前中后景。** 前景是伸向茶包的手和低矮台沿；中景左侧茶棚完成主交易，右后方布店卷布形成次动作；后景只有相连街巷和不同材质的棚檐／窗格。茶棚与布店不能是复制房屋换一块招牌。

**因果动作计划。** 顾客递券→摊主接券放妥→递出茶包→顾客收货转身，给街巷让出动线。布店只做小幅卷布动作，不开第二条抢眼交易。第4段第二行书外字幕转入纸艺世界，下一次翻页才呈现作坊。

| 顾客1、茶商1、布店人物1；主交易活动前臂4段，卷布前臂2段 | 主人脚底2点、次人物1点；`TRADE_CONTACT`在台沿，先券后货，两次接触顺序分明 |

### CH05 纸艺开工：两个人围绕同一张纸接力

玩家理解与搭档接力的任务，无真实操作或订单生成。计划程序产出为`CH05`章节集合、`craft_sheet`单纸工序状态、交接归属及工位锚点；按第7节CH05路径保存，版本`v06_20261112`。

**主体与关键瞬间。** 两位原始工匠在贯通的院子与印坊间接应，目光看向同一张刚抄出的纸。效果图选取靠近双槽晾架的交接瞬间：一人从槽边送纸，另一人空手接纸。两人是正在做事的搭档，不站在五个工位前合影。

**前中后景。** 前景是抄纸槽边及两人的交接通道；中景保留恰好两挂位的晾架和空共享台；后景通过敞开的连续屋檐看见印刷台、盖印台及靠外的交付位置。门依附墙或木构，不出现孤立门扇。五工位围成可工作的院坊，不沿纸页边缘平均排成图标列表。

**因果动作计划。** 一张纸从固定帘框脱离→在两人接应下进入晾架的一处→干纸送到印刷台出现墨纹→盖印后出现朱印→成票停在交付位，下一章完成对外交付。沿同一物件ID顺序切换状态；角色可以临时换岗，不把两人定义为固定专属职业。工序可在叙事中压缩，动作顺序不能省略成同时亮起的五个图标。若8秒内难读，先减少装饰运动与多余走位，不增加第二张纸或复制人物来表示步骤。

| 原始两位工匠各1；躯干各1、左右前臂各2，共4活动前臂；头身轮廓不改 | 每人`FOOT_ROOT`、`HAND_ITEM`、`LOOK_TARGET`；`HANDOFF_CONTACT`在两人可及处，接触时切换纸的唯一归属 |

**F01验收情景。** 与原图对照两人的帽发、五官、衣饰、色彩、比例均未重设计；任何关键帧只有一张在制纸，不出现两人各抱一叠纸；双槽清楚但只用一个，五工位加共享台无缺失；交接前后纸的接触与归属连续，工序黑墨／朱印有先后。第5章不做双人票肖像的独立特写。

### CH06 合做交子：首票从作坊真正交到人手里

玩家观看首票交付并收到开工邀请，不在开场替玩家提交订单。计划程序产出为`CH06`章节集合、`first_delivery`窗口交接、停稳及书外标题时机；按第7节CH06路径保存，版本`v06_20261112`。

**主体与关键瞬间。** 延续同一作坊，交付窗口开向街巷。一位工匠从内侧递出首张组合票，另一位在身后让出位置、望向接收方；窗口外的匿名顾客伸手接住。效果图抓住票在双方指间交接的瞬间，让“第一单完成”由人的反应和接触成立，不由巨型票券升空成立。

**前中后景。** 交付台沿和收票的手在前景，票面稍向镜头转动；中景是两位工匠与依附作坊的窗口；后景只留可见的院坊一角和通向街巷的路。第5章的建筑材料和摆放关系延续，第6章用更少背景保证票与手清楚。

**因果动作计划。** 成票从交付位移到工匠手中→送至窗口接触点→顾客接住后收向胸前→工匠松手并与搭档交换短暂目光→书外出现正式标题。票跟随手与台面，不悬浮上升；标题不立在书页里，不做第二次盖印。角色表情只作原有五官的轻微姿态变化，不能改变人物造型。

## 5. 锚点、拆件及程序共同约定

采用Blender场景约定：X为书宽方向、Y从书前缘指向后缘、Z向上；纸页打开时以统一`PAGE_GROUND`高度为脚底基准。中缝沿Y，固定建筑分别归属左页或右页；跨页的道路仅在视觉上连续，不能用一块刚性房屋跨住两页导致无法翻页。导向Unity时再由维护者转换坐标，不宣称与其现有工程已联调。

| 接口 | 计划要求 |
|---|---|
| `BOOK_ROOT / PAGE_L / PAGE_R` | 一个书根点、两页归属；页叠与镜头使用同一书尺寸；六图比较时不换书型 |
| `HINGE_BASE` | 固定轮廓薄片以底边为转轴，V折／平行折脚与主体同组；全场景先分4—6个主要深度层并保留空气间隙；收合需验证而非靠隐藏穿插 |
| `FOOT_ROOT` | 人物脚底落纸面；人物移动与负重／手势分层，禁止滑动整张立板而没有接地关系 |
| `HAND_* / CONTACT / ITEM_SOCKET` | 手持、交接点、台面物料点分离；纸在任一时刻只有一个承托归属，接触后切换父级且保持世界位置连续 |
| `SHEET_01` | 游戏段唯一在制物；状态为湿纸→干纸→黑墨→朱印，持物与状态不通过复制物体实现 |
| `POSE_START / CONTACT / RELEASE / REST` | 每个主要动作留开始、接触、释放、停稳四个可检查姿态；书页翻动前物件回到可收合状态 |
| `CH01`—`CH06` | 章节集合独立；共用资产引用同一源，不在各章重新生成不同身份角色；静帧与动画都可追溯到章节效果图版本 |

拆件交付记录每件的源效果图、透明边缘、画布尺寸、基准单位、根点、正面朝向、局部遮挡补画和所属页。活动前臂从肘／袖口拆，保留被遮住部分；纸券四边完整，不能从整图裁下带别人的手。AI效果图的纸纤维、光影不可作为固定在贴图上的错误接触影重复投射，3D阶段要核对实际灯光。

### 5.1 从效果图到素材，必须重新建立正视层

效果图负责镜头、情境、材质和造型方向。素材图负责可重复贴到真实几何上的表面与轮廓，两者不是同一种交付。后续生成以角色原图和已定稿效果图作外形／配色约束，输出正视、等比例、无透视收缩、无景深和无场景投影的独立层；不把效果图直接裁剪／抠底后改名为3D纹理。

- 角色：完整正视躯干、左右前臂与必要侧面按原始身份对应，遮挡处补全。可以保留纸层自身的轻微边缘材质，不保留投在桌面／邻人上的阴影；姿态与景深在3D里形成。
- 票券、纸、钱、帘框、门窗：正视矩形或真实剪纸轮廓，完整四边，无梯形透视；普通纸的湿／干／黑墨／朱印分层，不用四张不同透视角度的纸冒充同一物件。
- 工位与建筑：先生成正视印绘的轮廓景片，屋瓦、木构、柜架优先画在薄纸上，门窗需要透空或前后错层时才拆；只为工位接触补必要的薄折台面，不做完整厚墙、屋架或逐瓦实体。效果图内已经烘焙的俯视台面不能直接贴到另一张台面上再透视一次。
- 地面和材质：纸纤维、木纹、瓦片色纸、铺地纹样生成平铺或正视的平面材料，不含人物脚影、书中缝、远近大小变化或书外木桌。透明纹理边缘无白边，阴影由场景灯光产生。

### 5.2 素材阶段的优先顺序（仍为计划）

先整理6张实际效果图的统一问题和拆件差异，再生成以下最小可验证组；其余装饰不抢在角色、交接和工位之前批量生产。

| 优先级 | 建议先做的素材 | 用途与避免的返工 |
|---|---|---|
| 1 | 原始两工匠的分层正视工作稿；单张纸4状态；首款票面图形层 | 先锁定身份与纸张尺度，防止后续每章变脸或把透视票券当材质；不重设计原角色 |
| 2 | 正视帘框、晾架两槽、印刷台、盖印台及工具接触面；窗口／交付台 | 先验证一张纸与手、槽、台面的真实接触，消除“工位是画在竖卡上的桌子”问题 |
| 3 | 历史小券两型、钱袋／担筐／扁担，以及匿名人物躯干与交接前臂 | 覆盖前四章共用的负重、存钱、递券、换货动作，避免先做一大批不能接触的整身摆拍纸卡 |
| 4 | 各章铺面／官办／院坊的正视轮廓薄片、门窗透空层、必要纸折柜台；第5—6章复用 | 用印绘和前后层次表达建筑，几何只负责薄纸、折脚及必要台面，不升级成复杂微缩房屋 |
| 5 | 纸／木／色纸材质与少量茶货、布、植物等生活细节 | 统一材质后补叙事环境，按六图所需生成，不靠同一棵树或巨山重复填空 |

这一顺序只安排素材生产，不表示现在已生成任何上述素材或开始3D。素材完成后，才用真实书页、独立纸景和几何工位做最小动作验证，再扩展六章。
