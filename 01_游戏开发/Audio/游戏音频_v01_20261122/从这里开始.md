# 《交子赶工记》首关声音包

双击同目录的 **试听.html**。先选一首配乐，再点工位或语音卡，可以听双人同时操作时各层的关系。想听朱印落下的瞬间，可依次选择「正式回合」的配乐、擦印、揭纸、盖印。每个素材也可以单独打开。

## 一局怎么用声音

《首关声音试听.m4a》把一局压成约 68 秒。0:00 听标题，0:07 选角，0:13 教学，0:21 开张。0:24 起循序听提帘、挂纸、递纸、刷墨、盖印和收票，0:40 暂停，0:45 继续，0:49 转赶工，1:00 收工结算。时间为试听剪辑点。

| 阶段 | 音乐与操作 |
| --- | --- |
| 入坊 | 开场影片沿用自己的声音，进入主界面后起标题曲。选关和选角共用第二首。两位玩家分别就绪时，可各听自己所选钱灵的一句台词。 |
| 教学 | 教学曲给提帘的水声和旁白留出空间。教学停表，完成或跳过后清掉工位循环，再播开张信号。 |
| 三分钟正式回合 | 两位玩家共用一首作坊曲。院子和室内靠脚步材质区分。两人可以同时开工，每个活跃工位保留一个独立循环。 |
| 最后半分钟 | 建议剩余 30 秒时淡入赶工曲，只播一次报时。最后 5 秒用短木点读秒。两个阈值是本次配音与示范混音的设计值，可在试玩后调整。 |
| 暂停与设置 | 局内暂停时存下原曲位置、停工位声，切到《檐下歇手》。恢复时续原曲，只有仍有效的工位才恢复声音。主页进入设置沿用标题曲。 |
| 收工 | 归零播收工声。有星和零星各用一首结算曲。星逐颗点亮，图鉴首次解锁单独给声。零星也可能交付过正式票并解锁收藏。 |

## 工位和按钮

- 抄纸、擦印、扇风是三个循环。按住且有效时起声，松手、离开、暂停或完成时短淡出。泡泡和墨墩的加速技能缩短播放时间，循环保持原音高。
- 递交时，只在游戏确认所有权转移后播一次。同一件物品免叠两人的拿放声。两槽晾架分别在挂上与干透时发声。烘栗只为正在扇的湿纸槽发声。
- 提帘、揭下墨票、朱印落定各有独立收尾。章落在纸上时触发盖印音。交付最后一张只播整单收讫，其余收票播窗口接单。
- 界面焦点变更、确认、返回、翻页、拒绝、滑条刻度和玩家准备均可单独触发。脚步按院地与木地板各备三条，按落脚轮换。
- 设置页对应总音量、音乐、音效三组。语音可随音效旋钮控制。语音同时最多一句，双人连续就绪时可依次播放。试听混音在说话时将配乐下压约 7 dB，结束后约 0.3 秒恢复。

## 素材与来源

| 入口 | 内容 |
| --- | --- |
| BGM | 八首原创器乐循环，曲目说明见同目录。 |
| SFX | 32 个原创合成拟音，48 kHz、16 位、单声道 PCM WAV。 |
| Voice | 豆包语音合成的八条中文短句，24 kHz、16 位、单声道 PCM WAV。沿用项目开场 v06 的四位角色、旁白及财神音色。voices.json 含台词、音色与触发场景。 |
| 音频事件表.csv | 全部 48 个资源的相对路径、用途、触发条件、循环方式和解码时长。 |
| 本机曲库参考.m3u8 | 按场景排列的八首本机录音。用支持 M3U8 的播放器在有原 G 盘的电脑打开；列表引用 G 盘路径。 |

本版音乐从头编写，音效由程序合成。曲库参考表记录了八首本机录音的场景用途，压缩包仅保存这些录音的播放路径。首关引擎内的触发、空间声像和双人同屏听感仍待正式工程联调。
