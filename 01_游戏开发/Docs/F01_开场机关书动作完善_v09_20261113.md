# F01 开场机关书 v09：采用人物、分段动作、弯曲翻页与楷体字幕
更新：2026-11-13。范围：开场动画制作区，未修改或验证另一位开发者的 Unity 工程。

## 玩家看到的更新
用户明确指定品红底 NPC 与双主角图集，本版以其完整原图为依据，不再使用 v06 效果图中的前景人物脸。暖色纸艺书景与末章修正后的正面铺面延续 v08。

字幕使用本机华文楷体（STKaiti），34 px、深棕色、两行居中，继续放在书外。视频里的字已经渲染，无需玩家安装字体。本包没有分发系统字体文件；可编辑页面通过 local 字体加载，渲染检查确认加载成功。

翻页采用固定书脊的曲面网格，页角先抬起，页身弯曲，落下时减速；纸纤维、背面色差、阴影与薄纸边随翻动变化。每次翻页 1.75 秒，景物先收拢。空书底层与平面街道底层分开，避免把整幅照片连背景一起压扁。

## 故事顺序
0—8 秒铁钱难行；8—16 秒纸券初生；16—24 秒官办交子；24—32 秒一纸通市；32—46 秒纸艺开工；46—56 秒合做交子。前四章先讲交子的缘起、发展与用途，后两章引入架空纸艺作坊与玩家任务。字幕不写角色姓名，最后两秒邀请玩家开工。

单件持物、单份订单、五工位加共享台、双槽晾纸继续按首关规则；动画的工序演出不代替游戏规则联调与真人试玩。历史文字来源沿用 v08 记录，没有新增历史断言。

## 复现
在 Scripts/开场机关书_v09_20261113 下：
1. Node 24 运行 render.mjs --preview，审查动作与翻页采样。
2. Node 24 运行 render.mjs --motion-qa，检查人物区域帧变化、品红残留、字体加载和 101 个翻页时刻的书脊及边界。
3. Node 24 运行 render.mjs，输出 1344 帧到 work/frames。
4. 使用含 NumPy 的 Python 运行 create_audio.py；本机采用 Blender 附带 Python，未用 Blender 重建人物。
5. PowerShell 运行 encode.ps1 合成音画、全片解码；Node 24 运行 render.mjs --qa 与 verify_media.mjs。
6. 仅提交本次 v09 文件与本说明，推送后比对远端 main。

## 边界
本版是固定视角 2.5D 分段纸偶动画与程序控制的曲面纸页，不能任意旋转视角，不是完整三维骨骼角色或纸张物理模拟。图集色键与部件分离用于这段开场，不自动等同于已清理验收的 Unity 生产精灵。自动检查验证播放与几何/帧变化，不代替美术最终审看；音频无旁白。
