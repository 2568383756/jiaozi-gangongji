# F01 开场纸书 v05：桌面立体书

本版采用摊在桌面上的双页书册，纸景从页上立起，书页沿装订线自动翻动。六个8秒段落依次为铁钱难行、纸券初生、官办交子、一纸通市、纸艺开工、合做交子，总长48秒。前三段讲交子的历史背景，第4段转入架空纸艺世界，第5—6段引入双人合作与组合交子。

本目录的音频、渲染、编码和验证工具独立指向 `01_游戏开发/Art/开场纸书_v05_20261111`。v04 的工程、脚本和正在进行的渲染保持独立。

## 文件与入口

| 文件 | 用途 |
|---|---|
| `build_book.py` | 主制作脚本：建立桌面书册、纸景立起、翻页、抽拉签、字幕与灯光；实际文件由主制作任务维护 |
| `create_audio.py` | 生成48秒原创拨弦音乐、翻纸、抽拉和两次印章音，不含语音旁白 |
| `render_frames.py` | 以1920×1080、24 fps输出1—1152帧，支持源指纹校验、续渲和保守静止帧复用 |
| `encode_video.ps1` | 检查1152张帧及其源标记，编码H.264／AAC MP4，成功后替换最终视频 |
| `verify_delivery.mjs` | 最终视频完整解码，检查规格、帧序列、源指纹、音轨时点和交付文件SHA-256 |
| `validate_source.py` | 针对v05摊开书册、POPUP立起、自动抽拉签、历史与游戏资产分离及翻页镜头边界的只读核验 |

生成音轨为 `assets/开场配乐与纸声_v05.wav`，44.1 kHz、16-bit立体声。配乐由加法合成生成，纸声由过滤噪声生成，无外部采样与下载音源。翻页起点为6.9、14.9、22.9、30.9、38.9秒，持续1.1秒；每段0.15—1.8秒为抽拉纸声；37秒、43秒为印章强调音。对应来源和技术参数写入 `assets/开场音轨来源_v05.json`。

## 本机运行

依赖：Blender 5.3.0（内含Python与NumPy）、FFmpeg、Node.js。以下命令在本目录运行。

```powershell
$introBlender = 'D:/steam/steamapps/common/Blender/blender.exe'
$introSource = '../../Art/开场纸书_v05_20261111/开场纸书_v05_20261111.blend'

# 先准备声音，再由主制作脚本建立并打包源工程。
& $introBlender --background --factory-startup --python ./create_audio.py

# 源工程完成后，只读审计缓存是否适用，不渲染、不保存源工程。
& $introBlender --background $introSource --python-exit-code 1 --python ./render_frames.py -- --audit-cache

# 渲染全部帧；也可以在 -- 后传入起止帧，例如 -- 1 192。
& $introBlender --background $introSource --python-exit-code 1 --python ./render_frames.py

# 帧完成后再编码。播放器、分镜总览、制作核验文件齐全后再验证交付。
./encode_video.ps1
node ./verify_delivery.mjs
```

`encode_video.ps1` 使用 `C:/Program Files/ffmpeg/bin/ffmpeg.exe`，帧目录固定为 `work/frames_final/frame_%04d.jpg`。视频输出为 `Art/开场纸书_v05_20261111/开场纸书_v05_20261111.mp4`。视频以0.6秒淡入，最后0.8秒淡出，保留48秒总时长。

## 静止帧复用边界

渲染脚本保留源文件SHA-256和逐帧标记。源文件发生变化时，同编号旧帧需要重新渲染，不能因为文件存在就跳过。每帧渲染或复用完成后才写入该帧源标记。

缓存只在审计通过后启用：动画仅允许对象位置、旋转、缩放和渲染可见性；无形态键、骨骼、模拟、粒子、实例、约束、动画材质、动画网格、动画灯光数据、动画场景或合成器；修改器只允许静态BEVEL和SOLIDIFY；关闭运动模糊。相机数据仅允许 ortho_scale 关键帧，其他数据动画仍拒绝。每帧签名额外包含相机类型、正交尺度、镜头焦距、shift、clip及传感器参数，防止镜头拉远时误用静止帧。材质节点和驱动表达式也需通过白名单检查。静态TexCoord仅允许Generated/UV输出且不能引用外部对象；静态VectorMath和ValToRGB节点无时间输入，颜色渐变元素完整纳入材质签名。桌面书册的固定旋转和纸景的对象X轴立起属于对象变换，但仍须对最终v05源重新审计，不继承v04的审计结论。

每帧都先更新依赖图，再对实际可渲染对象的求值矩阵、数据身份、静态材质签名以及相机和灯光计算精确状态哈希，不舍入矩阵。只有同一源指纹下完全相同的状态才复制已有完整JPEG。已续用的帧同样参与状态计算。日志分别报告 `rendered`（实际渲染）、`reused`（同状态复制）和 `resumed`（已有有效帧）。任何审计条件不满足，自动恢复逐帧渲染。

`work/` 保存中间帧、源标记、审计日志和预览，不提交Git。历史版本保留；本版最终素材、视频、工程和核验记录单独保存。交付验证脚本检查媒体完整性，不证明画面没有穿插或构图问题；仍需审看关键帧与整片播放。此目录不包含Unity游戏联调结果。自动播放开场、跳过与标题页衔接按同版本播放器和F01交接说明处理，音频/渲染脚本不写入游戏教学或收藏状态。
