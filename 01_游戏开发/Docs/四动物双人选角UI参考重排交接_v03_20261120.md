# 四动物双人选角 UI 参考重排交接 v03

文档版本：v03_20261120；当前画面组合为总览 v04、四张详情 v03。主任务 F02，关联 F01／F13／F16。本次交付整页美术图片与说明；四动物真实三维模型、可操作 UI、Unity 预览相机与联调均未制作。本机资料不作为另一位开发者工程的运行结果。

## 当前采用方向

按用户三张参考重排，并落实最新纠正：画面保持明亮，使用中青绿、米灰纸与少量旧金；四动物分别位于各自屏风内；所有角色导航及玩家状态中的角色图标，统一为带印泥斑驳、缺口与纸纹的头部剪影印章，不采用彩色头像。P1 青绿圆标、P2 朱红菱标及文字编号继续保留，印章头像不能替代玩家归属标识。

总览按最新纠正采用 v04：保留折屏斜透视和屏扇折角，四动物按泡泡、递蕉、墨墩、烘栗横向排列，各自保持在对应屏扇内。屏风角色采用平面手绘，取消角色立体体块与模型台座；未选显示剪影，已选显现彩色。删除每栏选择按钮，底部水獭与熊猫章改为清晰轮廓和简化阴刻。剪影只表示未选，不表示角色未解锁；彩色显现依据 `selectedId`，不以 `ready` 决定，未准备但已选的玩家仍显示彩色。

四张详情继续采用 v03，沿用参考的斜切墨色、大片留白、居中大角色、右上大书法名、左侧小印章导航和少量倾斜纸卡；墨色面积与浓度受控，避免暗沉。详情中的角色保留纸纤维、手绘纹理、纸片切边与柔和立体体块，保留角色下方单一选择按钮。总览最新的平面化与删除每栏按钮要求不反向改写四张详情。

页面仅保留姓名、技能短句及必要按钮／双人状态，不放人物长介绍、技能参数段落、教学说明、表情图解、战力雷达或额外技能。长规则保存在交接资料与合同中。v01 厚框方案、v02 暗色方案及本轮 v03 总览均退为历史迭代，当前入口为总览 v04 与详情 v03，不覆盖旧图。

## 双人状态与既有合同

本轮仅更新美术呈现。交互继续沿用[双人选角状态合同 v01](../Art/四动物双人选角UI_v01_20261120/双人选角状态合同_v01_20261120.json)的输入、状态、归属、冲突、取消与进入规则；其中的旧图片路径及静态示例仍属于 v01 历史图，不作为本轮美术入口。四个角色的名称和完整旧技能参数，以[现役角色与组合合同 v01](设定同步_v01_20261120/当前角色与组合合同_v01_20261120.json)为准。

每人浏览焦点、已选角色与准备状态仍分开。P1 沿用 A／D、F，P2 沿用左右方向键、主键盘斜杠，Esc 逐级返回。总览删除每栏可见按钮，不删除 F／斜杠确认，也不取消玩家归属；屏幕点击请求仍必须携带明确的 `playerId`。详情选择按钮与确认键均原子选中并准备；已准备后仅能取消自己的准备再改选。重复选择搭档角色时拒绝当前请求，不能更改搭档。只有两个不同角色均准备后才可进入。详情返回、取消后焦点同步、进入快照、等待期间操作锁定与失败恢复均沿用原合同，本轮不修改。

本轮实际静态状态示例：总览 P1 泡泡已选未准备，P2 墨墩已准备，因此泡泡和墨墩显现彩色，递蕉和烘栗保持剪影；底部以水獭青绿头章、熊猫朱红头章配合玩家编号和状态。四张详情中 P1 浏览对应角色、尚未选择确认，P2 在泡泡／递蕉／烘栗详情中为墨墩已准备，在墨墩详情中为泡泡已准备。进入按钮均不可用。详情的浏览对象不代表已经占用该角色，正式游戏须读取真实 `selectedId`。图中的玩家状态、印章与按钮文案均须动态绑定，不能把示例写死为运行逻辑。

## 验收边界

本轮已检查五张文件的存在、实际尺寸、RGB 格式和逐页画面。总览 v04 为明亮纸底、屏内平涂角色，未选剪影与已选彩色对应正确；每栏选择按钮已删除，仅保留返回与右下禁用入坊入口。底部水獭与熊猫头章清晰，角色导航和状态图标均无彩色头像。四张详情保持斜切留白、大角色、大书法名、少量倾斜纸卡与简短技能，选择按钮位于角色下方，P1／P2 状态一致。

图中的角色仅为静态美术呈现，不是可交付三维网格或可操作角色；总览平面显现效果也尚未制作成动态交互。后续仍需四动物模型、详情预览姿态、印章与 UI 拆件、可编辑文字、预览相机／材质适配及对方 Unity 工程验证；联调时另记实际工程、提交版本与测试结果。本轮不据图片宣称模型、选角功能或第一关程序验收完成。
