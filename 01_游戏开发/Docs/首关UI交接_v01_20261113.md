## 视觉与尺寸

界面采用纸张层叠、朱印、木刻线框与宋代工坊元素，延续当前场景的鲜明色彩。米色纸 `#fff2cf`、朱红 `#bf4932`、靛蓝 `#294c67`、银杏金 `#e8ad3b`、墨棕 `#3f3025`。玩家实际界面 P1 用青绿 `#357c73`，P2 用朱红，同时保留 P1／P2 与角色姓名，不能仅靠颜色识别玩家或错误状态。

设计基准为 1920×1080。正式 Unity 接入建议左右安全边距 48 px、上下 36 px；字号在基准下为正文 26 px、辅助文字 22 px、按钮 28 px、倒计时 48 px。缩放后关键文字不得小于 16 px，交互区域至少 44×44 px。验收尺寸为 1280×720、1920×1080、1280×800。窗口改变时按锚点重排；场景机位保持比例，不用强行拉伸弥补留白。

左上只放当前一份订单及实收；右上放剩余时间与暂停。底部左右各一个玩家持物与操作提示；工位进度靠近对应工位。A／B 晾纸槽必须各有自己的进度及可取反馈。中央和下方中央保留给游戏操作，常驻 HUD 面积目标不超过视口约 25%。长操作说明进入暂停页，错误信息短时显示，不能压住订单或时间。

标题可用宋体风格字形，HUD 数字和键位使用清楚的中文无衬线。没有把系统字体文件复制为可分发资产；Unity 字体与 TMP／UI Toolkit 中文字库需由程序方按实际授权与目标构建检查。动态订单数、时间、分数、按键和提示由程序绘制，不能烘焙到贴图。

## 组件与接入原则

本批实际交付 23 组原创 SVG＋PNG 组件、2 张从角色 v02 原生模型渲染的透明角色图，以及 3 张原字节引用图，共 28 张 PNG。另复用一份现有开场配乐用于试听；来源与哈希记录在资源清单。人物图展示真实新手模型，没有重新生成角色概念图。

|---|---:|---|---|

| `button_primary_normal/hover/pressed/disabled/focus` | 5 | 320×96 | 48／28／48／28 |

| `badge_p1/p2` | 2 | 128×128 | 等比缩放；P1/P2 文字单独绘制 |
| `portrait_zhituan`、`portrait_yintao` | 2 | 768×768，RGBA | 等比缩放，保留透明留白 |

25 张新输出组件与人物 PNG 的尺寸及实际透明像素检查全部通过。源 SVG 可编辑，角色图可由本批 Blender 渲染脚本重建。`panel_paper` 四边切片采用 64 px，完整保护距边 55 px 内的角饰。九宫格边距与透明边界以资源清单为准；拉伸仅作用于允许区域，图标不能按九宫格分割。网页面板已实际使用 `panel_paper.svg` 九宫格，按钮用 CSS 实现与 PNG 拆件相同的视觉方向；正式 Unity 使用对应 PNG 参数重建。不要把整屏截图当作单张背景覆盖游戏。

按键状态需区分正常、悬停、按下、禁用和键盘焦点；选中角色与确认角色是不同状态。禁用不能仅降低透明度而不说明原因。确认标记、锁定图标和星标为可叠加组件。界面打开弹层时焦点进入弹层，关闭后回到原按钮，输入不得穿透到局内角色。

程序只从规则层接收快照或成功事件：界面不能自行转移纸张、加分、完成订单或解锁收藏。`ui_contract.json` 是正式接入建议，不要求程序沿用网页内部变量名。建议携带 `roundId` 与单调递增 `revision`，过滤晚到的上一局通知；结算按 `roundId` 去重。

## 规则与反馈文案

首关只有一份订单、单件持物、五工位加单槽共享台、两个独立晾纸槽。不要复用旧概念图中的三订单条、抱多张纸或额外压纸工序。两人均可做全部普通工序，本批不展示未确认的技能加成。

拒绝反馈至少区分“没有可操作目标”“这里还没有纸”“需要干纸／需要黑墨交子／需要朱印交子”“这个位置已满”“还没有完成”“搭档手里已有物品”“本轮已结束”。反馈只解释失败，原物件与进度不得因此清除。

正式订单量按 1、1、2 循环。前两单各一张完成，再为第三单交一张，共 3 张、2 单、50 分，当前单进度为 1/2。时间到保留已交纸的分数，手持和台上未交物不计分。星级只按完成单数 2／4／6，不能按交纸张数或分数替代。

正式轮次结算且至少交一张，才解锁本局组合；零星也能解锁。教学、重开和中途返回不解锁新收藏。P1／P2 调换不改变字典序组合键。最高分与最高星分别更新，不能要求两个纪录来自同一轮。

## 浏览器演示和正式程序的边界

网页用于评审页面、焦点、动态字段与反馈，不含 Unity 实时场景、实体碰撞和正式双人控制器。场景是已有模型的渲染图；演示中的操作与状态切换不能当作完整关卡已实现。演示存储与正式 Unity 存档分开，不能把浏览器本地记录写成生产存档的原子替换与备份验收。

音量、全屏和分辨率在浏览器中受浏览器权限与平台限制：网页“预览画布宽度”仅限制界面画布最大宽度，不修改 Windows 分辨率；全屏使用浏览器全屏接口。试听采用已有开场配乐，按钮反馈音用于音效音量核对；不表示已经新作正式标题或局内音乐。Unity 需要接入总音量、音乐、音效、全屏、窗口分辨率和操作说明；本批不提供改键功能。具体网页行为以页面说明和本批测试记录为准。
