## 2. 项目与制作目标

《交子赶工记》是架空宋代成都纸张世界中的双人合作制作游戏。两人协作完成“院中造纸 → 屋内印刷 → 盖印 → 交付”，合作收益来自并行加工、备料、交接和临时换岗。游戏题材围绕交子与造纸印刷文化，印出的票面含两位所选工匠的形象。

两位制作者为数字媒体艺术背景，采用手绘与 AI 辅助美术、AI 辅助程序的工作方式。当前三维制作方向为 Tripo3D／模型制作工具输出角色与道具，接入 Unity，在固定高位斜俯视镜头中呈现纸艺 2.5D 效果。开发优先做完整第一关。原对话曾给出约六周制作周期，当前剩余时间未更新。

## 3. 当前规则基线

以下秒数、速度、门槛沿用设计文档的初始调试值；最终平衡需要双人试玩。

| 项目 | 实现口径 |
|---|---|
| 平台与玩家 | Windows 同机同屏双人；首批角色纸团、印桃；各自可以完成全部普通工序 |
| 输入 | P1 WASD 移动、F 拿放、G 按住加工；P2 方向键、主键盘 / 拿放、. 按住加工；Esc 暂停 |
| 交互 | 每人一件；前方 90°、1.2 米内最近可见目标高亮后操作；墙体阻隔；同帧争抢按稳定编号裁决 |
| 交接 | 面向空手搭档点按递交；接收者无需同时按键；共享台单槽可存中间品 |
| 加工 | 松手保留进度，进度属于工位；搭档可续做，同槽同帧只接受一人加工 |
| 订单 | 同时一单，普通关无单独订单超时；首关数量按 1、1、2 循环 |
| 计分 | 每交一张 +10，完成整单再 +10；三张、两单合计 50 分 |
| 回合 | 停表教学交一张后清场，正式计时 180 秒；归零先关交互，再结算一次 |
| 星级 | 暂按 2／4／6 单对应一／二／三星；一星解锁下一关 |
| 收藏 | 正式轮次交过至少一张，结算解锁组合；教学及中途退出不解锁；零星但有正式交付可解锁 |
| 暂停与重开 | 暂停冻结局时、加工、干燥和 Boss；重开清持物、工位、订单及临时状态，保留已保存记录 |

工序对应的状态和资源如下。

| 工位 | 输入 → 输出 | 时间与容量 | 对应任务 |
|---|---|---|---|
| 抄纸槽 | 空手加工 → 湿纸留槽待取 | 按住 2 秒；待取物占位 | F05 |
| 双槽晾纸架 | 湿纸 → 干纸留架 | 每槽自动 4 秒，独立操作点与计时 | F06 |
| 印刷台 | 干纸 → 黑墨交子 | 按住 2 秒；成品取走后才接下一张 | F07 |
| 盖印台 | 黑墨交子 → 朱印交子 | 按住 1 秒 | F08 |
| 交付窗口 | 朱印交子 → 消耗并记入订单 | 一次点按，原子更新物件与分数 | F09 |

原料、墨、印泥无限，工具固定。材料错误、满槽、搭档满手等拒绝操作要显示原因，保留原物件和进度。压纸、纸捆等早期画面按视觉参考处理。纸团“双张搬运”已退出当前规则，单件持物继续生效。

技能尚为拟案。换人续加工时按标准工作量累计，只改变后续速率。六名工匠都直立，Boss 墨大嘴为四足纸兽。

六选二、不同角色、忽略左右顺序，共 15 款组合票。用两个角色 ID 排序生成键。票面共用底纸，黑墨层含双人木刻，朱印独立覆盖；手持、台面、结算和图鉴读取同一组合数据。首批只交纸团＋印桃一款，两个人的木刻必须随首款票一起交。

完整范围拟定三关普通关加一关 Boss。Boss 墨大嘴锁定工位上具体黑票／朱票与原槽位，预警 3 秒，取走即救出票；槽中换成新票也不能误伤。命中变废票，需拿去回收筐。时间参数初值为 20 秒首发、攻击与恢复各 1 秒、冷却 15 秒。技能、四关完整范围、六人是否开局全开放及 Boss 节奏继续按拟案管理。

## 5. 美术定稿与接入约定

古色纸艺、手绘线、大色块，纸张折面和层叠边缘清楚；宽方大头、短身体、短四肢、稍大眼睛、古装，角色体量一致但轮廓各有特色。保留干净的纸感，避免密集颗粒和小装饰。鹤与乌龟已替换为金丝猴与大熊猫，头顶方形饰物已取消。

镜头参考《胡闹厨房》的高位斜俯视、接近正交，角色、场景、道具使用同一尺度与朝向。院子和印坊贯通，门依附墙或木构；操作面、会车通道、纸张状态需要始终看得清。参考图中的摆放可随实际动线调整。

首组联调以 1 Unity 单位约 1 米、正 Y 向上、正 Z 朝前、脚底根点为初始约定。角色需手持锚点；工位需操作点、独立物料锚点和碰撞参考。模型文件与动画检查通过后再扩大批量。PNG 多视图、动作示意、整屏 UI 属于设计参考；是否已接入以运行记录为据。
