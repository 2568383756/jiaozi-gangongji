## 当前世界与四灵

财神府纸币司保存钱币长卷，四个钱灵进入长卷中的北宋益州忆境，和玩家一起恢复正在被“空白风”吹淡的交子故事。灵气来自理解与传递纸币手艺和信用约定，单纯重复印制不无限加灵气。忆境修复不改写真实历史；失败可重试，不让钱灵因一次失误永久消失。

玩家没有实体人类主角，画面不保留人类角色。财神仅以声音、祥云、金印出现；空白风是奇幻现象，没有实体大反派。旧墨大嘴和其攻击／废票链条作为历史暂停方案，不自动改名接入新世界。

四灵都能完成普通工序。加工按标准工作量累计，换人只改变后续速率，不清空也不重算已有进度；扇风松手或离开恢复普通速率。技能方向采用旧版，数值仍需联调与双人试玩验证。纸团／印桃及其能力退出当前阵容，旧人类存档不能直接改成动物成就。

原聊天助手曾把小熊猫写成“阿绒·掌印钱灵”。该称呼及掌印专长不作为现行角色定义：统一为烘栗，保留扇风技能。画面中的盖章可以是四灵都能做的普通工序，不从道具或动作反推新特技。

## 当前美术要求

最近可读聊天要求明显的国风手绘感：边缘勾线与墨线有变化，上色以平涂大色块为主，采用极端可爱的风格化比例，四灵之间有体形大小与图形轮廓对比，避免碎细节和粗犷涂抹。开屏可突出烘栗的构图主次与表情趣味，但不因此增加角色技能。

宽纸卷必须表现为连续完整的纸面，走势、转折与翻叠遮挡清楚，近大远小、有纵深，不能用零碎纸带拼出含糊空间。配色保持鲜明，不把全部画面降饱和；背景绿色克制，服装色与纸面分离。递蕉和泡泡身后可加少量安静远景，避免复杂或跳脱的背景夺走主体。

## 保持的首关规则

| 范围 | 当前口径 |
|---|---|
| 玩家与选角 | Windows 同机同屏双人，从四灵选两个不同角色；局内不切换 |
| 键位 | P1 WASD／F 拿放／G 按住加工；P2 方向键／主键盘斜杠拿放／句点按住加工；Esc 暂停 |
| 移动交互 | 默认速度 3 米每秒；前方 90°、普通交互 1.2 米；可见最近目标高亮，墙阻隔；同帧争抢稳定裁决 |
| 持物与加工 | 每人一件；搭档空手才可递交；共享台单槽；松手保留工位进度，同槽每帧仅一人加工 |
| 抄纸／晾纸 | 普通抄纸 2 秒、泡泡 1.4 秒；双槽独立自动干燥 4 秒，烘栗扇风按旧规则加速 |
| 印刷／盖印／交付 | 普通印刷 2 秒、墨墩 1.4 秒；盖印 1 秒；朱印票一次点按交付 |
| 订单计分 | 同时一单，无单独订单超时；首关数量 1／1／2 循环；每张 +10，整单再 +10，3 张 2 单为 50 分 |
| 教学与回合 | 停表教学交一张后清场，Enter 可跳过；正式 180 秒，归零关交互并只结算一次；动画 180 秒与回合时间相互独立 |
| 星级收藏 | 2／4／6 单暂对应 1／2／3 星；正式交过至少一张，在结算解锁本局组合；教学／中退不解锁，零星但有交付可以收藏 |
| 暂停重开 | 冻结局时、加工和干燥；重开清双手、槽位、订单与临时状态，保留已结算记录 |

五工位加共享台、双槽晾纸保持。打浆、压水、核验登记先用于原工序中的动作与提示表达，不据叙事自动扩成新工位或新输入系统。知识节点与数量分数分开设计，正式灵气奖励规则另行落到可测事件后再接入。

## 六组合与第一关制作顺序

四选二、不分左右且不允许同角自配，恰有六种组合：泡泡＋递蕉、泡泡＋墨墩、泡泡＋烘栗、递蕉＋墨墩、递蕉＋烘栗、墨墩＋烘栗。两个稳定 ID 排序生成组合键；手持、台面、结算与收藏读取同一组底纸、双肖像黑墨与朱印数据。旧人类首票不计入六款。

首关先校准一个动物与一台工位，再补齐四灵、六组合数据和页面流程。可先做泡泡＋墨墩样本，属于制作顺序建议，不是用户确认的固定搭档或角色解锁条件。四头像、四动物基础模型与动作是当前阵容资源目标；四木刻和六组合模板避免选角后出现不存在的票面。正式六款细节美术在 F18 跟踪，复用资产不重复计数。

F01—F15继续覆盖首关闭环；F16 改为四灵旧技能联调，不再指“在两个人类后新增四人”；F17 为首关之后的普通关扩展；F18 从十五款改为六款。F19 保留编号追踪空白风表现，具体玩法待确认；F20 旧废票回收分支冻结。不能从旧四关表推导现在仍要做实体 Boss 关。
