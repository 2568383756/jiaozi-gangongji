## 接口要求

- 播放器事件：`intro-finished`，`detail={reason:'ended'|'skipped',runId,version:'v10'}`。每轮只发一次，重播产生新轮次。
- 分层源：等待 `window.ready` 后调用 `renderFrame(seconds)`，时间范围 0—56。随机跳转为确定性渲染；动画不依赖累计帧数。
- `CharacterMotion.init` / `draw(ctx,chapter,localSeconds,{background:false})`：用户图谱的纸偶、道具与前景遮挡；`paint` 供远景行人复用同一人物画法。
- `EnvironmentMotion.init` / `drawBackground`：局部 UV 变形云朵、枝叶、灯笼、门帘及远景街道人群，并绘制新增行人；不叠放第二张静止云。书边、书脊和镜头固定。
- `Ambience.drawUnder` / `drawOver`：水面线条与涟漪在人物下方，落叶在人物上方。水纹按河道、纸槽区域裁剪。
- `PageTurn.draw`：沿用 v09 曲面翻页，1.75 秒，固定书脊。当前制作方法为固定镜头的 2.5D 图层、纸偶关节和局部纹理变形，不是完整可旋转三维场景或物理纸张模拟。
- Unity 交接使用视频或重做同等时间线；此 HTML/WebGL 源不是 Unity 工程。宿主完成事件、自动启动、跳过和资源释放仍需另一位开发者在实际工程中验证。

## 验收情景与证据

1. 六章分别检查人物位移和递物；第 38 秒女孩走到印台前时面部完整，第 40—42 秒印刷、盖印，随后带票返回；末章顾客接票后退，两位工匠挥手。
2. 第一、四、六章行人在道路范围移动；云朵缓移不产生第二个残留云影；落叶沿弧线旋转并落地；流水、涟漪不越出指定水面。
3. 独立测试角色、落叶、云朵、水面，避免背景动了却误判角色也动了。26 项分层检查、6 项完整画面检查、字体实际载入、101 次翻页几何采样记录在 `动作与字体核验_v10.json`。
4. 检查固定书边、重复时间点渲染一致性、人物洋红残边、水纹越界。完整视频逐帧解码；验证 1344 帧、56 秒以及文件哈希，见 `媒体核验_v10.json`。
5. 播放器验证实际视频元数据、播放推进、暂停冻结、重复跳过仅回调一次、重播后自然结束、结束停播，见 `播放器核验_v10.json`。

关键帧已做画面检查；美术满意度由用户反馈继续修订。音轨完成文件和峰值检查，本轮没有真人听音验收。Unity 接入未测。
