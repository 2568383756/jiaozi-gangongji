## 2. 统一视觉语言

**主体采用几何剪纸拼贴与低面数折纸的视觉表现。** 这里描述二维画面的造型方法，不声称已有低模、绑定或可编辑三维资源。耳、口鼻、衣领、袖口、手爪与尾巴先形成完整清晰的剪影，再以少量相邻色面解释转折。色面边界要服务体积与结构，不能随意把脸和衣服切碎。

折线硬朗、轮廓利落，大色块先于纹样。通过纸层错位、有限折边和柔和短投影表现厚度；投影对应真实遮挡，方向和软硬统一。平印的图案不添加立体高度。角色不再以毛绒渲染、繁密毛发、大笔刷涂抹或全画面粗黑描边形成主要观感；允许少量内部线条说明五官和结构。

新参考确有局部纸纹、印刷网纹和底纸花纹，应保留其材料意味，但使用范围要克制：主体大色面干净，细纹集中在少量衬纸、折面或边缘。不能把纹理铺满角色和背景，也不能用脏污颗粒、高频噪点、密集小饰物代替设计。纸感主要来自造型、色面、层叠和投影，不靠全屏做旧。

纸卡、角贴、纸签和小标签属于同一套组件：使用一致的纸厚、折角尺度、边线和投影。卡片可轻微错位形成层次，重要文字和交互控件保持稳定可读；不让所有控件一起倾斜。每页以一个主要视觉和一个主要操作为重点，装饰围绕主体组织，保留空白，避免堆成拼贴杂物墙。

## 3. 配色、字形与页面尺度

以暖米白承托内容，人物／主要节点采用明确主色与辅助色，局部用更鲜明的颜色强调动作、工具或状态。参考中的朱红、青色、蓝紫、棕绿、土金展示的是可协调的色彩关系；不能把全项目统一理解为只用一种褐黄色，也不应整体降饱和。

制作时先为每个主体确定一组主辅色，再在相邻页面复用。四动物原有身份色和服装识别关系仍需保留，换成几何色面不等于随意换人。P1青绿、P2朱红承担玩家识别，不能被角色个人配色取代。v01列出的六个十六进制色值仅为旧建议，**不再作为唯一固定色板**；生成提示词采用的工作色值为暖米白 #F4E6C6、深褐 #3C2C25、朱红 #BC4931、青绿 #277B77、土金 #D6A443；单角底色另用红棕 #713F30。这些是提示词中的目标值，不是对 PNG 逐像素取色或用户已确认的最终色值。正式组件制作时再从确认稿登记精确色板。

同一功能共用字形、字重、标签形制和数字样式。标题可有简洁书法意味，正文与数据以可读为先；不把每一行信息都写成大书法，不以诗文、伪汉字或装饰小字填白。少量纹样可进入卡角、衬纸或分隔位置，不能跨页不断更换装饰体系。

游戏整页与本批四张角色设定均保持原来的横向构图；不得因参考是竖卡而改成竖版。1920×1080及安全边距64px仍仅为制作建议，不因参考卡尺寸而改游戏分辨率。已有近似16:9评审PNG不等于高清组件已完成。生成后的静态图还须拆分动态文字、按钮和状态层，才能接入游戏。

## 4. 保留的角色与交互合同

可选角色仍为泡泡／paopao（水獭）、递蕉／dijiao（金丝猴）、墨墩／modun（大熊猫）、烘栗／hongli（小熊猫），四选二、不重复、不分左右，共六款组合交子。它们的物种、体形差异、性格和可辨识道具保留，造型表现转为本轮几何剪纸语言。参考中的人类、犬神或狸猫不加入阵容；世界观保持宋代交子、造纸印刷与四钱灵，无可见人类主角。道具与装饰需转译为项目已有纸、印版、笔、扇、交子和宋风构件，不照搬原参考的异题材符号。

旧技能不变：泡泡抄纸1.4秒；递蕉向空手搭档递交2米，工位仍1.2米且受墙阻隔；墨墩印刷1.4秒；烘栗按住对单个湿纸槽扇风，总干燥速率2倍。数值仍为联调初值。本次不新增玩法、角色职业、工位或奖励系统。

选角继续采用连续长卷与四动物总览，不因竖卡参考自动改回四扇屏风或每栏选择按钮。选关保留印刷台／册页、多节点和“铜钱→纸张→交子”的视觉顺序，节点体量错落；印在纸面的背景和立起纸景明确区分。建筑的屋顶、梁柱、墙面与底座需使用同一透视和承托关系，简化不能破坏结构。

结算继续采用原版竖式交子加本局所选两动物头章，不恢复合影或另画横票。原票来源见[底票副本](../Art/选角与多关卡UI_参考重构_v05_20261121/参考/用户原资源_交子底票.png)。字体、纸签、头章和星级应服从本轮统一语言，但不破坏交子原票的币纹、文字、纸坊线描与朱印关系。原有[双人状态合同](../Art/四动物双人选角UI_v01_20261120/双人选角状态合同_v01_20261120.json)继续有效。
